## 1. 概述

### 1.1 为什么需要 Callbacks

在 AI 应用中，我们经常需要在关键节点执行自定义逻辑：

- **日志记录**：记录每个步骤的输入输出
- **性能监控**：测量各阶段耗时
- **成本追踪**：统计 Token 使用量
- **调试开发**：查看中间状态
- **异常处理**：统一处理错误


### 1.2 回调链原理

Eino 的 Callback 采用链式调用模式，每个 Handler 可以在前后执行逻辑：

```go
// 回调执行顺序
OnStart()      // 多个 Handler 依次执行
    ↓
  Handler1.OnStart
  Handler2.OnStart
  Handler3.OnStart
    ↓
  [执行主逻辑]
    ↓
OnEnd()        // 多个 Handler 依次执行
    ↓
  Handler1.OnEnd
  Handler2.OnEnd
  Handler3.OnEnd
```

### 1.3 应用场景

| 场景 | 使用场景 | 示例 |
|------|----------|------|
| 日志记录 | 调试、审计 | 记录每次 LLM 调用 |
| 性能监控 | 优化、告警 | 监控响应时间 |
| 成本追踪 | 成本控制 | 统计 Token 消耗 |
| 进度显示 | UI 集成 | 显示生成进度 |
| 错误处理 | 稳定性 | 统一异常捕获 |

## 2. Callback 接口

### 2.1 Handler 接口定义

```go
// Callback Handler 接口
// 位于：github.com/cloudwego/eino/callback

type Handler interface {
    // OnStart 开始执行时被调用
    OnStart(ctx context.Context, info *RunInfo)

    // OnEnd 执行结束时被调用
    OnEnd(ctx context.Context, info *RunInfo, err error)

    // OnError 发生错误时被调用
    OnError(ctx context.Context, info *RunInfo, err error)
}

// RunInfo 包含执行信息
type RunInfo struct {
    Type    RunType   // 执行类型（LLM/Tool/Retriever等）
    Name    string    // 节点名称
    Input   any       // 输入内容
    Output  any       // 输出内容
    Extra   map[string]any  // 额外信息
    StartAt time.Time // 开始时间
    EndAt   time.Time // 结束时间
}
```

### 2.2 HandlerBuilder 模式

```go
// HandlerBuilder 用于链式构建 Handler
// 位于：github.com/cloudwego/eino/callback

type HandlerBuilder interface {
    // Build 构建最终的 Handler
    Build(ctx context.Context) (Handler, error)
}

// 常用 Builder
func NewLogHandler() *LogHandlerBuilder
func NewMetricHandler() *MetricHandlerBuilder
func NewTracingHandler() *TracingHandlerBuilder
```

### 2.3 预定义 Hook 点

```go
const (
```

## 3. 基础使用

### 3.1 创建自定义 Handler

**功能说明**：创建一个简单的日志记录 Handler

**关键组件**：
- `callback.Handler`: 回调接口
- `Handler.OnStart/OnEnd`: 生命周期钩子

```go
package main

import (
	"context"
	"fmt"
	"time"

	"github.com/cloudwego/eino/callback"
)

// LogHandler 日志记录器
type LogHandler struct {
	Name string
}

func (h *LogHandler) OnStart(ctx context.Context, info *callback.RunInfo) {
	fmt.Printf("[%s] 开始执行: %s (类型: %s)\n",
		h.Name, info.Name, info.Type)
	fmt.Printf("  输入: %v\n", truncate(info.Input))
}

func (h *LogHandler) OnEnd(ctx context.Context, info *callback.RunInfo, err error) {
	duration := time.Since(info.StartAt)
	if err != nil {
		fmt.Printf("[%s] 执行失败: %s, 耗时: %v, 错误: %v\n",
			h.Name, info.Name, duration, err)
	} else {
		fmt.Printf("[%s] 执行成功: %s, 耗时: %v\n",
			h.Name, info.Name, duration)
		fmt.Printf("  输出: %v\n", truncate(info.Output))
	}
}

func (h *LogHandler) OnError(ctx context.Context, info *callback.RunInfo, err error) {
	fmt.Printf("[%s] 发生错误: %s, 错误: %v\n",
		h.Name, info.Name, err)
}

// 截断过长的输出
func truncate(v any) string {
	s := fmt.Sprintf("%v", v)
	if len(s) > 100 {
		return s[:100] + "..."
	}
	return s
}

// 使用示例
func main() {
	ctx := context.Background()
	handler := &LogHandler{Name: "MyApp"}

	// 使用 callback.Context 添加 Handler
	ctx = callback.WithHandlers(ctx, handler)

	// 在 Component 中使用 ctx
	// component.Invoke(ctx, input)
}
```

### 3.2 在 Runner 中注册回调

**功能说明**：在 ADK Runner 中注册 Callback Handler

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/cloudwego/eino/adk/agent"
	"github.com/cloudwego/eino/adk/runner"
	"github.com/cloudwego/eino/callback"
	"github.com/cloudwego/eino/chatbot/openai"
)

// CostTracker 用于追踪 API 调用成本
type CostTracker struct {
	TotalTokens    int
	PromptTokens   int
	CompletionTokens int
}

func (t *CostTracker) OnStart(ctx context.Context, info *callback.RunInfo) {
	fmt.Printf("开始调用: %s\n", info.Name)
}

func (t *CostTracker) OnEnd(ctx context.Context, info *callback.RunInfo, err error) {
	if err != nil {
		fmt.Printf("调用失败: %v\n", err)
		return
	}

	// 从 extra 信息中提取 token 使用量
	if usage, ok := info.Extra["usage"].(map[string]int); ok {
		t.PromptTokens += usage["prompt_tokens"]
		t.CompletionTokens += usage["completion_tokens"]
		t.TotalTokens = t.PromptTokens + t.CompletionTokens
	}

	fmt.Printf("调用成功，Prompt: %d, Completion: %d, Total: %d\n",
		t.PromptTokens, t.CompletionTokens, t.TotalTokens)
}

// 在 Runner 中使用
func main() {
	ctx := context.Background()

	// 创建 Agent
	model, _ := openai.NewChatModel(ctx, &openai.ChatModelConfig{
		APIKey: "your-api-key",
		Model:  "gpt-4o-mini",
	})
	agent, _ := agent.NewAgent(ctx, &agent.AgentConfig{
		Model: model,
		Tools: []agent.Tool{/* tools */},
	})

	// 创建 Runner 并注册 Callback
	tracker := &CostTracker{}
	run := runner.NewAgentRunner(ctx, agent,
		runner.WithCallbacks(tracker), // 注册 Callback
	)

	// 运行
	result, err := run.Run(ctx, "你好")
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println("Agent 回复:", result)
}
```

### 3.3 在 Graph 中使用回调

**功能说明**：在 Graph/Workflow 中集成 Callback

```go
package main

import (
	"context"
	"fmt"
	"time"

	"github.com/cloudwego/eino/callback"
	"github.com/cloudwego/eino/compose"
)

// TimingHandler 性能监控 Handler
type TimingHandler struct {
	Durations map[string]time.Duration
}

func (t *TimingHandler) OnStart(ctx context.Context, info *callback.RunInfo) {
	fmt.Printf("⏱ 开始: %s\n", info.Name)
}

func (h *TimingHandler) OnEnd(ctx context.Context, info *callback.RunInfo, err error) {
	duration := time.Since(info.StartAt)
	if h.Durations == nil {
		h.Durations = make(map[string]time.Duration)
	}
	h.Durations[info.Name] = duration

	if err != nil {
		fmt.Printf("❌ %s 失败: %v (耗时: %v)\n", info.Name, err, duration)
	} else {
		fmt.Printf("✅ %s 完成 (耗时: %v)\n", info.Name, duration)
	}
}

// 在 Graph 中使用
func main() {
	ctx := context.Background()

	handler := &TimingHandler{}

	// 通过 context 传递
	ctx = callback.WithHandlers(ctx, handler)

	// 创建 Graph
	g := compose.NewGraph[string, string]()
	g.AddNode("step1", step1Node)
	g.AddNode("step2", step2Node)
	g.AddEdge("step1", "step2")
	g.SetStart(func(ctx context.Context, input string) (string, error) {
		return input, nil
	})
	g.SetEnd(func(ctx context.Context, output string) (string, error) {
		return output, nil
	})

	graph, _ := g.Compile(ctx)

	// 执行时会自动触发 Callback
	graph.Invoke(ctx, "test input")
}
```

## 4. 高级用法

### 4.1 链式回调

**功能说明**：注册多个 Handler，每个都会按顺序执行

```go
package main

import (
	"context"
	"log"

	"github.com/cloudwego/eino/callback"
)

// ChainHandler 链式 Handler 管理
type HandlerChain struct {
	handlers []callback.Handler
}

func (hc *HandlerChain) Add(h callback.Handler) *HandlerChain {
	hc.handlers = append(hc.handlers, h)
	return hc
}

// 实现 callback.Handler
func (hc *HandlerChain) OnStart(ctx context.Context, info *callback.RunInfo) {
	for _, h := range hc.handlers {
		h.OnStart(ctx, info)
	}
}

func (hc *HandlerChain) OnEnd(ctx context.Context, info *callback.RunInfo, err error) {
	for _, h := range hc.handlers {
		h.OnEnd(ctx, info, err)
	}
}

func (hc *HandlerChain) OnError(ctx context.Context, info *callback.RunInfo, err error) {
	for _, h := range hc.handlers {
		h.OnError(ctx, info, err)
	}
}

// 使用链式 Handler
func main() {
	ctx := context.Background()

	chain := NewHandlerChain().
		Add(&LogHandler{Name: "Logger"}).
		Add(&MetricHandler{}).
		Add(&CostTracker{})

	ctx = callback.WithHandlers(ctx, chain)

	// 所有 Handler 都会被调用
	runAgent(ctx, "你好")
}

func runAgent(ctx context.Context, input string) {
	// ...
}
```

### 4.3 异步回调

**功能说明**：使用 goroutine 实现非阻塞回调

```go
package main

import (
	"context"
	"log"
	"sync"
	"time"

	"github.com/cloudwego/eino/callback"
)

// AsyncHandler 异步 Handler，不阻塞主流程
type AsyncHandler struct {
	ch     chan *callback.RunInfo
	wg     sync.WaitGroup
	closed bool
}

func NewAsyncHandler() *AsyncHandler {
	h := &AsyncHandler{
		ch: make(chan *callback.RunInfo, 100), // 带缓冲 channel
	}
	h.wg.Add(1)
	go h.processLoop() // 后台处理
	return h
}

func (h *AsyncHandler) processLoop() {
	defer h.wg.Done()
	for info := range h.ch {
		// 异步处理，如发送到监控系统
		sendToMonitoring(info)
	}
}

func (h *AsyncHandler) OnStart(ctx context.Context, info *callback.RunInfo) {
	if h.closed {
		return
	}
	select {
	case h.ch <- info:
	default:
		// channel 满时丢弃，避免阻塞
	}
}

func (h *AsyncHandler) OnEnd(ctx context.Context, info *callback.RunInfo, err error) {
	if h.closed {
		return
	}
	info.EndAt = time.Now() // 填充结束时间
	select {
	case h.ch <- info:
	default:
	}
}

func (h *AsyncHandler) Close() {
	h.closed = true
	close(h.ch)
	h.wg.Wait()
}

func sendToMonitoring(info *callback.RunInfo) {
	// 发送到 Prometheus, DataDog 等
	log.Printf("Async: %s completed in %v", info.Name, time.Since(info.StartAt))
}
```

## 5. 实际场景

### 5.1 场景一：完整日志系统

**功能说明**：实现一个生产级别的日志记录系统

```go
package main

import (
	"context"
	"encoding/json"
	"fmt"
	"os"
	"time"

	"github.com/cloudwego/eino/callback"
)

// LogEntry 日志条目
type LogEntry struct {
	Timestamp   time.Time              `json:"timestamp"`
	Level       string                `json:"level"`
	Type        callback.RunType      `json:"type"`
	Name        string                `json:"name"`
	Duration    time.Duration         `json:"duration"`
	InputSize   int                   `json:"input_size"`
	OutputSize  int                   `json:"output_size"`
	Error       string                `json:"error,omitempty"`
	Extra       map[string]any        `json:"extra,omitempty"`
}

// ProductionLogger 生产级日志记录器
type ProductionLogger struct {
	output   *os.File
	level    string
	includeInput  bool
	includeOutput bool
}

func NewProductionLogger(output *os.File) *ProductionLogger {
	return &ProductionLogger{
		output:         output,
		level:          "INFO",
		includeInput:   true,
		includeOutput: true,
	}
}

func (l *ProductionLogger) OnStart(ctx context.Context, info *callback.RunInfo) {
	entry := LogEntry{
		Timestamp: time.Now(),
		Level:     "INFO",
		Type:      info.Type,
		Name:      info.Name,
		InputSize: sizeOf(info.Input),
		Extra:     info.Extra,
	}
	l.write(entry)
}

func (l *ProductionLogger) OnEnd(ctx context.Context, info *callback.RunInfo, err error) {
	level := "INFO"
	if err != nil {
		level = "ERROR"
	}

	entry := LogEntry{
		Timestamp:  time.Now(),
		Level:      level,
		Type:       info.Type,
		Name:       info.Name,
		Duration:   time.Since(info.StartAt),
		InputSize:  sizeOf(info.Input),
		OutputSize: sizeOf(info.Output),
		Error:      errorToString(err),
	}
	l.write(entry)
}

func (l *ProductionLogger) write(entry LogEntry) {
	data, _ := json.Marshal(entry)
	fmt.Fprintln(l.output, string(data))
}

func sizeOf(v any) int {
	if v == nil {
		return 0
	}
	switch val := v.(type) {
	case string:
		return len(val)
	default:
		return len(fmt.Sprintf("%v", val))
	}
}

func errorToString(err error) string {
	if err == nil {
		return ""
	}
	return err.Error()
}

// 使用示例
func main() {
	// 输出到文件
	file, _ := os.OpenFile("app.log", os.O_CREATE|os.O_APPEND|os.O_WRONLY, 0644)
	defer file.Close()

	logger := NewProductionLogger(file)
	ctx := callback.WithHandlers(context.Background(), logger)

	// 运行应用
	run(ctx)
}
```

### 5.2 场景二：性能监控系统

**功能说明**：集成 Prometheus 监控

```go
package main

import (
	"context"
	"log"
	"net/http"
	"time"

	"github.com/cloudwego/eino/callback"
	"github.com/prometheus/client_golang/prometheus"
	"github.com/prometheus/client_golang/prometheus/promhttp"
)

// MetricsCollector Prometheus 指标收集器
type MetricsCollector struct {
	// 计数器
	requestTotal   *prometheus.CounterVec
	requestErrors  *prometheus.CounterVec

	// 直方图
	requestDuration *prometheus.HistogramVec

	// Gauge
	inProgress *prometheus.GaugeVec
}

func NewMetricsCollector() *MetricsCollector {
	m := &MetricsCollector{
		requestTotal: prometheus.NewCounterVec(
			prometheus.CounterOpts{
				Name: "eino_requests_total",
				Help: "Total number of requests",
			},
			[]string{"type", "name"},
		),
		requestErrors: prometheus.NewCounterVec(
			prometheus.CounterOpts{
				Name: "eino_requests_errors_total",
				Help: "Total number of errors",
			},
			[]string{"type", "name"},
		),
		requestDuration: prometheus.NewHistogramVec(
			prometheus.HistogramOpts{
				Name:    "eino_request_duration_seconds",
				Help:    "Request duration in seconds",
				Buckets: prometheus.DefBuckets,
			},
			[]string{"type", "name"},
		),
		inProgress: prometheus.NewGaugeVec(
			prometheus.GaugeOpts{
				Name: "eino_requests_in_progress",
				Help: "Number of requests in progress",
			},
			[]string{"type", "name"},
		),
	}

	prometheus.MustRegister(m.requestTotal, m.requestErrors,
		m.requestDuration, m.inProgress)

	return m
}

func (m *MetricsCollector) OnStart(ctx context.Context, info *callback.RunInfo) {
	m.requestTotal.WithLabelValues(string(info.Type), info.Name).Inc()
	m.inProgress.WithLabelValues(string(info.Type), info.Name).Inc()
}

func (m *MetricsCollector) OnEnd(ctx context.Context, info *callback.RunInfo, err error) {
	duration := time.Since(info.StartAt).Seconds()

	m.inProgress.WithLabelValues(string(info.Type), info.Name).Dec()
	m.requestDuration.WithLabelValues(string(info.Type), info.Name).Observe(duration)

	if err != nil {
		m.requestErrors.WithLabelValues(string(info.Type), info.Name).Inc()
	}
}

// 启动 Prometheus 端点
func main() {
	collector := NewMetricsCollector()

	// 启动 HTTP 服务
	http.Handle("/metrics", promhttp.Handler())
	go http.ListenAndServe(":9090", nil)

	// 使用 Collector
	ctx := callback.WithHandlers(context.Background(), collector)

	// 运行应用
	log.Println("Prometheus metrics available at :9090/metrics")
	run(ctx)
}
```

### 5.3 场景三：Token 成本追踪

**功能说明**：追踪 LLM 调用的 Token 消耗和成本

```go
package main

import (
	"context"
	"fmt"
	"sync"

	"github.com/cloudwego/eino/callback"
)

// TokenInfo Token 使用信息
type TokenInfo struct {
	Model           string
	PromptTokens    int
	CompletionTokens int
	TotalTokens     int
	Cost            float64
}

// CostTracker Token 成本追踪器
type CostTracker struct {
	mu        sync.Mutex
	tokens    map[string]*TokenInfo  // 按模型分组
	totalCost float64

	// Token 价格表（每 1M tokens 的价格）
	Prices map[string]float64
}

func NewCostTracker() *CostTracker {
	return &CostTracker{
		tokens: make(map[string]*TokenInfo),
		Prices: map[string]float64{
			"gpt-4o":          5.00,   // $5 / 1M prompt
			"gpt-4o-mini":     0.15,   // $0.15 / 1M prompt
			"gpt-3.5-turbo":   0.50,   // $0.50 / 1M prompt
		},
	}
}

func (ct *CostTracker) OnStart(ctx context.Context, info *callback.RunInfo) {
	// 记录开始
}

func (ct *CostTracker) OnEnd(ctx context.Context, info *callback.RunInfo, err error) {
	if err != nil {
		return
	}

	// 从 extra 中提取 usage 信息
	usage, ok := info.Extra["usage"].(map[string]any)
	if !ok {
		return
	}

	ct.mu.Lock()
	defer ct.mu.Unlock()

	model := info.Extra["model"].(string)
	promptTokens := int64(0)
	completionTokens := int64(0)

	if v, ok := usage["prompt_tokens"].(int); ok {
		promptTokens = int64(v)
	}
	if v, ok := usage["completion_tokens"].(int); ok {
		completionTokens = int64(v)
	}

	// 更新统计
	if _, exists := ct.tokens[model]; !exists {
		ct.tokens[model] = &TokenInfo{Model: model}
	}

	ct.tokens[model].PromptTokens += int(promptTokens)
	ct.tokens[model].CompletionTokens += int(completionTokens)
	ct.tokens[model].TotalTokens += int(promptTokens + completionTokens)

	// 计算成本
	price := ct.Prices[model]
	if price > 0 {
		cost := float64(promptTokens+completionTokens) / 1_000_000 * price
		ct.tokens[model].Cost += cost
		ct.totalCost += cost
	}
}

func (ct *CostTracker) GetReport() string {
	ct.mu.Lock()
	defer ct.mu.Unlock()

	report := "=== Token 使用报告 ===\n"
	for model, info := range ct.tokens {
		report += fmt.Sprintf("\n模型: %s\n", model)
		report += fmt.Sprintf("  Prompt: %d tokens\n", info.PromptTokens)
		report += fmt.Sprintf("  Completion: %d tokens\n", info.CompletionTokens)
		report += fmt.Sprintf("  Total: %d tokens\n", info.TotalTokens)
		report += fmt.Sprintf("  成本: $%.4f\n", info.Cost)
	}
	report += fmt.Sprintf("\n总计成本: $%.4f\n", ct.totalCost)
	return report
}

// 使用示例
func main() {
	tracker := NewCostTracker()
	ctx := callback.WithHandlers(context.Background(), tracker)

	// 运行 LLM 调用
	runLLMCalls(ctx)

	// 输出报告
	fmt.Println(tracker.GetReport())
}
```

### 5.4 场景四：调试开发工具

**功能说明**：开发阶段使用的调试 Handler

```go
package main

import (
	"context"
	"encoding/json"
	"fmt"
	"strings"
	"time"

	"github.com/cloudwego/eino/callback"
)

// DebugHandler 开发调试 Handler
type DebugHandler struct {
	depth     int
	maxDepth  int
	traceMode bool
}

func NewDebugHandler() *DebugHandler {
	return &DebugHandler{
		maxDepth:  5,
		traceMode: true,
	}
}

func (d *DebugHandler) OnStart(ctx context.Context, info *callback.RunInfo) {
	if d.depth >= d.maxDepth {
		return
	}

	indent := strings.Repeat("  ", d.depth)
	fmt.Printf("%s🔵 [%s] %s\n", indent, info.Type, info.Name)

	if d.traceMode {
		if input := d.formatValue(info.Input); input != "" {
			fmt.Printf("%s   📥 Input: %s\n", indent, input)
		}
	}

	d.depth++
}

func (d *DebugHandler) OnEnd(ctx context.Context, info *callback.RunInfo, err error) {
	d.depth--
	if d.depth >= d.maxDepth {
		return
	}

	indent := strings.Repeat("  ", d.depth)

	if err != nil {
		fmt.Printf("%s   ❌ Error: %v\n", indent, err)
	} else {
		if d.traceMode {
			if output := d.formatValue(info.Output); output != "" {
				fmt.Printf("%s   📤 Output: %s\n", indent, output)
			}
		}
		fmt.Printf("%s✅ 完成 (耗时: %v)\n", indent, time.Since(info.StartAt))
	}
}

func (d *DebugHandler) formatValue(v any) string {
	if v == nil {
		return ""
	}

	switch val := v.(type) {
	case string:
		if len(val) > 200 {
			return val[:200] + "..."
		}
		return val
	case []byte:
		return string(val)
	default:
		data, err := json.Marshal(val)
		if err != nil {
			return fmt.Sprintf("%v", val)
		}
		result := string(data)
		if len(result) > 200 {
			return result[:200] + "..."
		}
		return result
	}
}

// 使用示例
func main() {
	handler := NewDebugHandler()
	ctx := callback.WithHandlers(context.Background(), handler)

	fmt.Println("=== 开始调试追踪 ===")
	run(ctx)
	fmt.Println("=== 调试追踪结束 ===")
}
```

## 6. 与 Tracing 集成

### 6.1 OpenTelemetry 集成

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/cloudwego/eino/callback"
	"go.opentelemetry.io/otel"
	"go.opentelemetry.io/otel/attribute"
	"go.opentelemetry.io/otel/exporters/stdout/stdouttrace"
	"go.opentelemetry.io/otel/sdk/trace"
)

// OTelHandler OpenTelemetry 追踪 Handler
type OTelHandler struct {
	tracerName string
	provider   *trace.TracerProvider
}

func NewOTelHandler(serviceName string) (*OTelHandler, error) {
	// 创建 stdout exporter（生产环境使用 OTLP exporter）
	exporter, err := stdouttrace.New(stdouttrace.WithPrettyPrint())
	if err != nil {
		return nil, err
	}

	// 创建 TracerProvider
	tp := trace.NewTracerProvider(
		trace.WithBatcher(exporter),
		trace.WithResource(
			trace.ResourceAttributes(
				attribute.String("service.name", serviceName),
			),
		),
	)

	otel.SetTracerProvider(tp)

	return &OTelHandler{
		tracerName: serviceName,
		provider:   tp,
	}, nil
}

func (h *OTelHandler) OnStart(ctx context.Context, info *callback.RunInfo) {
	tracer := otel.Tracer(h.tracerName)

	// 创建 span
	ctx, span := tracer.Start(ctx, string(info.Type)+":"+info.Name)
	info.Extra["otel_span"] = span
	info.Extra["otel_ctx"] = ctx
}

func (h *OTelHandler) OnEnd(ctx context.Context, info *callback.RunInfo, err error) {
	// 从 extra 中获取 span
	span, ok := info.Extra["otel_span"].(interface{ End() })
	if ok {
		if err != nil {
			span.End()
		}
	}
}

func (h *OTelHandler) Shutdown(ctx context.Context) error {
	return h.provider.Shutdown(ctx)
}

// 使用示例
func main() {
	handler, err := NewOTelHandler("eino-app")
	if err != nil {
		log.Fatal(err)
	}
	defer handler.Shutdown(context.Background())

	ctx := callback.WithHandlers(context.Background(), handler)

	// 运行应用，调用信息会被记录到 OpenTelemetry
	run(ctx)
}
```

## 7. 常见问题

### Q1: Callback 没有被触发

**可能原因**：
- 没有正确传递 context
- Handler 没有正确实现接口
- Component 不支持 callback

**排查方法**：
1. 检查是否使用了 `callback.WithHandlers(ctx, handler)`
2. 检查 Handler 是否实现了所有必需方法
3. 确认 Component 支持 callback

**解决方案**：
```go
// 确保正确传递 context
ctx := callback.WithHandlers(context.Background(), handler)
result, err := component.Invoke(ctx, input)
```

### Q2: Handler 执行顺序混乱

**问题**：多个 Handler 的执行顺序不确定

**解决方案**：
- 使用 HandlerChain 显式控制顺序
- 按注册顺序执行（后注册的先执行）

### Q3: 性能影响

**问题**：Callback 导致性能下降

**解决方案**：
1. 使用异步 Handler
2. 避免在 Handler 中进行阻塞操作
3. 限制日志输出量

### Q4: 如何在 Handler 间共享数据

**解决方案**：
```go
// 使用 context 传递
type Key string

ctx := context.WithValue(ctx, Key("shared_data"), value)

// 在 Handler 中读取
value := ctx.Value(Key("shared_data"))
```
