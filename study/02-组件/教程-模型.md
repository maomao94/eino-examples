## 1. 概述

### 什么是 ChatModel

ChatModel 是 Eino 框架中与大语言模型通信的核心组件。它定义了与 LLM 交互的统一接口。

```
┌─────────────────────────────────────────────────────────────────┐
│                      ChatModel 架构                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │                     ChatModel 接口                        │  │
│  │                                                           │  │
│  │   Generate(ctx, messages) → Message                       │  │
│  │   Stream(ctx, messages) → StreamReader[Message]            │  │
│  └───────────────────────────────────────────────────────────┘  │
│                               │                                   │
│          ┌────────────────────┼────────────────────┐            │
│          │                    │                    │            │
│          ▼                    ▼                    ▼            │
│   ┌────────────┐     ┌────────────┐     ┌────────────┐         │
│   │   OpenAI   │     │    Ark    │     │ Anthropic  │         │
│   │            │     │  (豆包)   │     │  (Claude)  │         │
│   └────────────┘     └────────────┘     └────────────┘         │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### ChatModel 接口定义

```go
// 基础接口
type BaseChatModel interface {
    // 同步生成
    Generate(ctx context.Context, input []*schema.Message,
             opts ...Option) (*schema.Message, error)

    // 流式生成
    Stream(ctx context.Context, input []*schema.Message,
           opts ...Option) (*schema.StreamReader[*schema.Message], error)
}

// 带工具绑定的安全版本（推荐）
type ToolCallingChatModel interface {
    BaseChatModel
    WithTools(tools []*schema.ToolInfo) (ToolCallingChatModel, error)
}
```

## 2. 快速开始

### 最简示例

```go
package main

import (
    "context"
    "fmt"

    "github.com/cloudwego/eino/components/model/openai"
    "github.com/cloudwego/eino/schema"
)

func main() {
    ctx := context.Background()

    // 1. 创建模型
    model, err := openai.NewChatModel(ctx, &openai.ChatModelConfig{
        Model:  "gpt-4o-mini",
        APIKey: "your-api-key",
    })
    if err != nil {
        panic(err)
    }

    // 2. 构造消息
    messages := []*schema.Message{
        schema.SystemMessage("你是一个有帮助的助手"),
        schema.UserMessage("你好"),
    }

    // 3. 调用
    resp, err := model.Generate(ctx, messages)
    if err != nil {
        panic(err)
    }

    fmt.Println(resp.Content)
}
```

## 3. 支持的模型

### 3.1 OpenAI

```go
import "github.com/cloudwego/eino/components/model/openai"

model, err := openai.NewChatModel(ctx, &openai.ChatModelConfig{
    Model:       "gpt-4o",              // 模型名称
```

## 4. 调用方式

### 4.1 Generate（同步调用）

```go
// 简单调用
resp, err := model.Generate(ctx, messages)

// 带选项
resp, err := model.Generate(ctx, messages,
    compose.WithTemperature(0.7),
    compose.WithMaxTokens(1000),
)
```

### 4.2 Stream（流式调用）

```go
stream, err := model.Stream(ctx, messages)
defer stream.Close()

for {
    chunk, err := stream.Recv()
    if errors.Is(err, io.EOF) {
        break
    }
    fmt.Print(chunk.Content)
}
```

### 4.3 完整流式示例

```go
package main

import (
    "context"
    "errors"
    "fmt"
    "io"
    "log"

    "github.com/cloudwego/eino/components/model/openai"
    "github.com/cloudwego/eino/schema"
)

func main() {
    ctx := context.Background()

    model, _ := openai.NewChatModel(ctx, &openai.ChatModelConfig{
        Model:  "gpt-4o-mini",
        APIKey: "your-key",
    })

    messages := []*schema.Message{
        schema.UserMessage("给我讲一个关于机器人的故事，100字左右"),
    }

    stream, err := model.Stream(ctx, messages)
    if err != nil {
        log.Fatal(err)
    }
    defer stream.Close()

    fmt.Println("AI: ", end="")

    total := 0
    for {
        chunk, err := stream.Recv()
        if errors.Is(err, io.EOF) {
            fmt.Println()
            fmt.Printf("共 %d 字符\n", total)
            break
        }
        if err != nil {
            log.Fatal(err)
        }

        fmt.Print(chunk.Content)
        total += len(chunk.Content)
    }
}
```

## 6. 工具调用

### 6.1 WithTools（线程安全）

```go
// 1. 获取工具信息
toolInfos := []*schema.ToolInfo{
    {
        Name: "calculator",
        Desc: "执行数学计算",
        ArgsSchema: &CalculatorRequest{},
    },
}

// 2. 使用 WithTools 创建带工具的模型
// 注意：每次调用 WithTools 返回新的实例，线程安全
chatModel, err := model.WithTools(toolInfos)
if err != nil {
    panic(err)
}

// 3. 调用
resp, err := chatModel.Generate(ctx, messages)
```

### 6.2 工具调用响应

```go
resp, err := chatModel.Generate(ctx, messages)

// 检查是否有工具调用
if len(resp.ToolCalls) > 0 {
    for _, tc := range resp.ToolCalls {
        fmt.Printf("工具: %s\n", tc.Function.Name)
        fmt.Printf("参数: %s\n", tc.Function.Arguments)
    }
}
```

### 6.3 完整工具调用流程

```go
package main

import (
    "context"
    "encoding/json"
    "fmt"
    "log"

    "github.com/cloudwego/eino/components/model/openai"
    "github.com/cloudwego/eino/schema"
)

type CalcReq struct {
    A  int    `json:"a"`
    B  int    `json:"b"`
    Op string `json:"op"`
}

func main() {
    ctx := context.Background()

    model, _ := openai.NewChatModel(ctx, &openai.ChatModelConfig{
        Model:  "gpt-4o",
        APIKey: "your-key",
    })

    // 创建带工具的模型
    toolInfos := []*schema.ToolInfo{
        {
            Name: "calculator",
            Desc: "执行数学计算，支持加减乘除",
            ArgsSchema: &CalcReq{},
        },
    }

    chatModel, _ := model.WithTools(toolInfos)

    // 调用
    messages := []*schema.Message{
        schema.UserMessage("计算 100 + 200 等于多少？"),
    }

    resp, err := chatModel.Generate(ctx, messages)
    if err != nil {
        log.Fatal(err)
    }

    // 处理工具调用
    if len(resp.ToolCalls) > 0 {
        tc := resp.ToolCalls[0]

        // 解析参数
        var req CalcReq
        json.Unmarshal([]byte(tc.Function.Arguments), &req)

        fmt.Printf("调用工具: %s\n", tc.Function.Name)
        fmt.Printf("参数: a=%d, b=%d, op=%s\n", req.A, req.B, req.Op)

        // 执行计算
        var result int
        switch req.Op {
        case "add": result = req.A + req.B
        case "sub": result = req.A - req.B
        case "mul": result = req.A * req.B
        case "div": result = req.A / req.B
        }

        // 返回结果
        toolMsg := schema.ToolMessage(
            fmt.Sprintf(`{"result": %d}`, result),
            tc.ID,
        )

        // 再次调用获取最终回复
        messages = append(messages, resp)
        messages = append(messages, toolMsg)

        finalResp, _ := chatModel.Generate(ctx, messages)
        fmt.Printf("最终回复: %s\n", finalResp.Content)
    } else {
        fmt.Printf("直接回复: %s\n", resp.Content)
    }
}
```

## 7. 最佳实践

### 7.1 错误处理

```go
resp, err := model.Generate(ctx, messages)
if err != nil {
    // 分类处理
    switch {
    case errors.Is(err, context.Canceled):
        // 用户取消
        return
    case errors.Is(err, context.DeadlineExceeded):
        // 超时
        return
    case strings.Contains(err.Error(), "rate limit"):
        // 限流
        time.Sleep(time.Second)
        // 重试
    default:
        // 其他错误
        log.Printf("API error: %v", err)
    }
}
```

### 7.2 重试机制

```go
// 简单重试
var resp *schema.Message
var err error
for i := 0; i < 3; i++ {
    resp, err = model.Generate(ctx, messages)
    if err == nil {
        break
    }
    time.Sleep(time.Duration(i+1) * time.Second)
}
```

### 7.3 Token 计算

```go
resp, err := model.Generate(ctx, messages)
if err != nil {
    log.Fatal(err)
}

// 访问使用量
if resp.ResponseMeta != nil && resp.ResponseMeta.Usage != nil {
    fmt.Printf("Input tokens:  %d\n", resp.ResponseMeta.Usage.InputTokens)
    fmt.Printf("Output tokens: %d\n", resp.ResponseMeta.Usage.OutputTokens)
    fmt.Printf("Total tokens:  %d\n", resp.ResponseMeta.Usage.TotalTokens)
}
```

### 7.4 流式收集

```go
stream, _ := model.Stream(ctx, messages)

// 收集完整响应
var fullContent string
for {
    chunk, err := stream.Recv()
    if errors.Is(err, io.EOF) {
        break
    }
    fullContent += chunk.Content
}
```

### 7.5 并行调用

```go
// 使用 errgroup 并行调用
var g errgroup.Group
var results []*schema.Message

for _, msg := range messages {
    msg := msg
    g.Go(func() error {
        resp, err := model.Generate(ctx, []*schema.Message{msg})
        if err == nil {
            results = append(results, resp)
        }
        return err
    })
}

if err := g.Wait(); err != nil {
    log.Fatal(err)
}
```

## 8. 常见问题

### Q1: 如何选择模型？

| 场景 | 推荐模型 | 理由 |
|------|---------|------|
| 快速响应 | gpt-4o-mini | 便宜、快速 |
| 高质量 | gpt-4o | 能力最强 |
| 本地部署 | Ollama | 隐私、无 API 费用 |
| 国内服务 | 豆包 (Ark) | 稳定、低延迟 |

### Q2: 如何处理限流？

```go
// 方法1: 添加延迟
for i := 0; i < 10; i++ {
    resp, err := model.Generate(ctx, messages)
    if err == nil {
        break
    }
    time.Sleep(time.Second * 5)
}

// 方法2: 使用信号量限制并发
sem := make(chan struct{}, 5)  // 最多5个并发
```

### Q3: 如何使用代理？

```go
// 创建代理客户端
proxyURL, _ := url.Parse("http://proxy:8080")
transport := &http.Transport{Proxy: http.ProxyURL(proxyURL)}
httpClient := &http.Client{Transport: transport}

model, _ := openai.NewChatModel(ctx, &openai.ChatModelConfig{
    Model:      "gpt-4o-mini",
    APIKey:     "key",
    HTTPClient: httpClient,
    BaseURL:    "https://api.openai.com/v1",
})
```

### Q4: 如何处理上下文长度？

```go
// 方法1: 截断历史
if len(messages) > 20 {
    messages = messages[len(messages)-20:]
}

// 方法2: 摘要后替换
summary := summarizeHistory(olderMessages)
messages = append([]*schema.Message{summary}, messages[10:]...)
```

### Q5: 如何调试？

```go
// 启用详细日志
model, _ := openai.NewChatModel(ctx, &openai.ChatModelConfig{
    Model:  "gpt-4o-mini",
    APIKey: "key",
    HTTPClient: &http.Client{
        Transport: &loggingTransport{},  // 自定义日志transport
    },
})
```
