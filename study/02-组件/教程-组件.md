## 1. Components 概述

### 1.1 组件类型

| 组件 | 说明 | 主要接口 |
|------|------|---------|
| **Model** | LLM 模型 | ChatModel、ToolCallingChatModel |

## 2. Model 模型

### 2.1 接口定义

```go
// ChatModel - 基本聊天接口
type ChatModel interface {
    Generate(ctx context.Context, messages []*schema.Message, opts ...Option) (*schema.Message, error)
    Stream(ctx context.Context, messages []*schema.Message, opts ...Option) (*schema.StreamReader[*schema.Message], error)
}

// ToolCallingChatModel - 支持工具调用的模型
type ToolCallingChatModel interface {
    ChatModel
    WithTools(tools []*schema.ToolInfo) (ToolCallingChatModel, error)
}
```

### 2.2 使用示例

```go
import "github.com/cloudwego/eino-ext/components/model/ark"

// 创建 ARK 模型（字节豆包）
arkModel, err := ark.NewChatModel(ctx, &ark.ChatModelConfig{
    APIKey: os.Getenv("ARK_API_KEY"),
    Model:  os.Getenv("ARK_MODEL_NAME"),
})

// 基本调用
messages := []*schema.Message{
    schema.SystemMessage("你是一个助手"),
    schema.UserMessage("你好"),
}
response, err := arkModel.Generate(ctx, messages)

// 流式调用
sr, err := arkModel.Stream(ctx, messages)
for {
    chunk, err := sr.Recv()
    if err == io.EOF { break }
    fmt.Print(chunk.Content)
}
```

### 2.3 工具绑定

```go
// 准备工具信息
toolInfos := []*schema.ToolInfo{
    {
        Name:        "search",
        Description: "搜索互联网",
        Parameters:  searchSchema,
    },
}

// 绑定工具到模型
chatModelWithTools, err := arkModel.WithTools(toolInfos)

// 调用时模型可以决定是否调用工具
messages := []*schema.Message{
    schema.UserMessage("帮我搜索一下今天的新闻"),
}
response, err := chatModelWithTools.Generate(ctx, messages)

// 检查是否有工具调用
if len(response.ToolCalls) > 0 {
    for _, tc := range response.ToolCalls {
        fmt.Printf("调用工具: %s, 参数: %s\n", tc.Function.Name, tc.Function.Arguments)
    }
}
```

### 2.4 HTTP 传输模型

```go
import "github.com/cloudwego/eino/components/model/httptransport"

// 使用 HTTP 传输创建模型
model, err := httptransport.NewChatModel(ctx, &httptransport.ChatModelConfig{
```

## 3. Tool 工具

### 3.1 工具接口

```go
// BaseTool - 工具基础接口
type BaseTool interface {
    Info(ctx context.Context) (*schema.ToolInfo, error)
}

// InvokableTool - 可调用工具
type InvokableTool interface {
    BaseTool
    InvokableRun(ctx context.Context, argumentsInJSON string, opts ...Option) (string, error)
}

// RunnableTool - 泛型可运行工具
type RunnableTool[Input any, Output any] interface {
    BaseTool
    Run(ctx context.Context, input Input) (Output, error)
}
```

### 3.2 创建工具

#### 方式一：使用 utils.InferTool（推荐）

```go
import "github.com/cloudwego/eino/components/tool/utils"

// 定义请求和响应类型
type SearchReq struct {
    Query string `json:"query"`
    Limit int    `json:"limit"`
}

type SearchResp struct {
    Results []string `json:"results"`
    Total   int      `json:"total"`
}

// 实现工具函数
searchFunc := func(ctx context.Context, req *SearchReq) (*SearchResp, error) {
    results := []string{"结果1", "结果2"}
    return &SearchResp{Results: results, Total: len(results)}, nil
}

// 创建工具
searchTool, err := utils.InferTool(
    "search",        // 工具名称
    "搜索互联网获取信息", // 工具描述
    searchFunc,      // 实现函数
)
```

#### 方式二：使用 schema.NewRunnableTool

```go
import "github.com/cloudwego/eino/schema"

// 创建工具
tool := schema.NewRunnableTool(
    // Info 函数
    func(ctx context.Context) (*schema.ToolInfo, error) {
        return &schema.ToolInfo{
            Name:        "calculate",
            Description: "执行数学计算",
            Parameters:  calculateSchema,
        }, nil
    },
    // Run 函数
    func(ctx context.Context, input string) (string, error) {
        // 解析输入
        var req CalculateRequest
        json.Unmarshal([]byte(input), &req)

        // 执行计算
        result := req.A + req.B

        return fmt.Sprintf("%d", result), nil
    },
)
```

### 3.4 工具到 Schema 转换

```go
// 将工具转为 LLM 可用的 ToolInfo
func toToolInfos(ctx context.Context, tools []tool.BaseTool) ([]*schema.ToolInfo, error) {
    toolInfos := make([]*schema.ToolInfo, 0, len(tools))
    for _, t := range tools {
        info, err := t.Info(ctx)
        if err != nil {
            return nil, err
        }
        toolInfos = append(toolInfos, info)
    }
    return toolInfos, nil
}
```

## 4. Retriever 检索器

### 4.1 接口定义

```go
// Retriever 文档检索器
type Retriever interface {
    // Retrieve 根据查询检索相关文档
    Retrieve(ctx context.Context, query string, opts ...Option) ([]string, error)

    // RetrieveWithScore 带相关性分数的检索
    RetrieveWithScore(ctx context.Context, query string, opts ...Option) ([]*schema.Document, error)
}
```

### 4.2 MultiQuery Retriever

MultiQuery 通过生成多个查询变体来提高召回率：

```go
import "github.com/cloudwego/eino/flow/retriever/multiquery"

// 创建多查询检索器
mqr, err := multiquery.NewRetriever(ctx, &multiquery.Config{
    // 查询改写处理器
    RewriteHandler: func(ctx context.Context, query string) ([]string, error) {
        // 使用 LLM 生成多个查询变体
        out, err := llm.Generate(ctx, []*schema.Message{
            schema.SystemMessage("生成3个不同的搜索查询，每行一个"),
            schema.UserMessage(query),
        })
        if err != nil {
            return nil, err
        }

        // 解析结果
        queries := strings.Split(out.Content, "\n")
        return queries, nil
    },

    MaxQueriesNum: 3,           // 最大查询数
    OrigRetriever: vectorStore, // 原始向量检索器
    FusionFunc:    nil,          // 合并策略（nil 使用默认去重）
})
```

### 4.3 Router Retriever

Router 根据查询类型路由到不同的检索器：

```go
import "github.com/cloudwego/eino/flow/retriever/router"

// 创建路由检索器
router, err := router.NewRetriever(ctx, &router.Config{
    // 检索器映射
    Retrievers: map[string]retriever.Retriever{
        "technical": techRetriever,   // 技术文档
        "business":  businessRetriever, // 业务文档
        "legal":     legalRetriever, // 法律文档
    },

    // 路由器函数
    Router: func(ctx context.Context, query string) ([]string, error) {
        // 根据查询内容决定路由
        var targets []string
        if strings.Contains(query, "代码") || strings.Contains(query, "API") {
            targets = append(targets, "technical")
        }
        if strings.Contains(query, "价格") || strings.Contains(query, "业务") {
            targets = append(targets, "business")
        }

        // 默认使用全部
        if len(targets) == 0 {
            targets = []string{"technical", "business", "legal"}
        }

        return targets, nil
    },

    // 合并策略（RRF 算法）
    FusionFunc: nil,
})
```

### 4.4 完整 RAG 示例

```go
func BuildRAG(ctx context.Context) (*compose.Workflow, error) {
    // 1. 创建向量存储
    vectorStore, err := volc_vikingdb.NewRetriever(...)

    // 2. 创建 MultiQuery 检索器
    mqr, err := multiquery.NewRetriever(ctx, &multiquery.Config{
        RewriteHandler: llmRewriteHandler,
        OrigRetriever:   vectorStore,
    })

    // 3. 创建 LLM
    llm, _ := ark.NewChatModel(...)

    // 4. 构建 Workflow
    wf := compose.NewWorkflow[string, string]()

    // 检索
    wf.AddLambdaNode("retrieve", compose.InvokableLambda(
        func(ctx context.Context, query string) ([]string, error) {
            return mqr.Retrieve(ctx, query)
        },
    )).AddInput(compose.START, compose.MapFields("", ""))

    // 构造 Prompt
    pt := prompt.FromMessages(schema.FString,
        schema.SystemMessage("基于以下资料回答问题：\n{context}"),
        schema.UserMessage("{question}"),
    )

    // 生成
    wf.AddChatModelNode("generate", llm)
    wf.End().AddInput("generate")

    return wf.Compile(ctx)
}
```

## 5. Prompt 提示词

### 5.1 ChatPrompt 接口

```go
// ChatPrompt 聊天提示词模板
type ChatPrompt[Param any] interface {
    compose.Runnable[Param, []*schema.Message]

    // Format 格式化模板
    Format(ctx context.Context, param Param) ([]*schema.Message, error)

    // IntoMessages 转换为 Messages
    IntoMessages() []*schema.Message
}
```

### 5.2 创建提示词

```go
import "github.com/cloudwego/eino/components/prompt"

// 方式一：FromMessages
pt := prompt.FromMessages(
    schema.FString,  // 使用 {var} 格式化
    schema.SystemMessage("你是一个 {role}，帮助用户{goal}"),
    schema.UserMessage("问题：{question}"),
)

// 格式化
messages, err := pt.Format(ctx, map[string]any{
    "role":     "助手",
    "goal":     "解答问题",
    "question": "什么是 AI？",
})

// 方式二：直接构建 Messages
messages := []*schema.Message{
    schema.SystemMessage("你是一个有帮助的助手"),
    schema.UserMessage("你好"),
}
```

### 5.3 模板变量

```go
// FString 格式化
pt := prompt.FromMessages(schema.FString,
    schema.SystemMessage("角色：{character}"),
    schema.UserMessage("{content}"),
)

// 使用结构体
type UserInput struct {
    Character string
    Content   string
}

messages, _ := pt.Format(ctx, UserInput{
    Character: "Python 专家",
    Content:   "解释装饰器",
})
```

### 5.4 复杂模板

```go
// 多轮对话模板
pt := prompt.FromMessages(schema.FString,
    schema.SystemMessage(`你是{bot_name}。
你的性格：{personality}
你的专长：{expertise}`),
    schema.AssistantMessage("{history}"),
    schema.UserMessage("{input}"),
)

// 带条件的模板
pt := prompt.FromMessages(schema.FString,
    schema.SystemMessage("{system_prompt}"),
    // 如果有上下文
    schema.UserMessage("上下文：{context}\n问题：{question}"),
)
```

## 6. ABTest 模型路由

### 6.1 ABRouterChatModel

ABRouter 可以根据请求动态选择不同的模型：

```go
import "github.com/cloudwego/eino/components/model/abtest"

// 创建路由器
router := abtest.NewABRouterChatModel(
    // 路由函数：根据输入选择模型
    func(ctx context.Context, messages []*schema.Message, opts ...model.Option) (string, model.BaseChatModel, error) {
        content := messages[len(messages)-1].Content

        // 根据内容选择模型
        if len(content) > 1000 {
            // 长文本用高级模型
            return "gpt-4", gpt4Model, nil
        }
        // 短文本用快速模型
        return "gpt-3.5", gpt35Model, nil
    },
)

// 使用
router = router.WithTools(toolInfos)
response, err := router.Generate(ctx, messages)
```

### 6.2 使用场景

| 场景 | 路由策略 |
|------|---------|
| 成本优化 | 简单问题用小模型，复杂问题用大模型 |
| A/B 测试 | 随机分配不同模型 |
| 负载均衡 | 轮询多个相同的模型实例 |
| 功能切换 | 按用户群组切换模型 |

## 7. Tool 中间件

### 7.1 中间件模式

```
┌─────────────────────────────────────────────┐
│              调用者                          │
└──────────────────┬────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│         Middleware 1 (JSON 修复)            │
└──────────────────┬────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│         Middleware 2 (错误清理)              │
└──────────────────┬────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│              原始工具                        │
└─────────────────────────────────────────────┘
```

### 7.2 JSON 修复中间件

```go
// 创建 JSON 修复器

// 配置

// 包装工具

```

### 7.3 错误移除中间件

```go
// 创建错误移除器
remover := errorremover.New()

// 配置要移除的模式
patterns := []string{
    `Rate limit exceeded.*`,
    `timeout.*`,
}

// 包装工具

```

### 7.4 自定义中间件

```go
// 创建自定义中间件
type loggingMiddleware struct {
    logger *log.Logger
}

func (m *loggingMiddleware) Wrap(base tool.BaseTool) tool.BaseTool {
    return &loggedTool{
        BaseTool: base,
        logger:   m.logger,
    }
}

type loggedTool struct {
    tool.BaseTool
    logger *log.Logger
}

func (t *loggedTool) InvokableRun(ctx context.Context, args string, opts ...tool.Option) (string, error) {
    t.logger.Printf("调用工具: %s, 参数: %s", t.Info(ctx).Name, args)
    result, err := t.BaseTool.InvokableRun(ctx, args, opts...)
    t.logger.Printf("工具结果: %s, 错误: %v", result, err)
    return result, err
}

// 使用
wrappedTool := (&loggingMiddleware{logger: myLogger}).Wrap(originalTool)
```

## 8. Document 文档处理

### 8.1 文档解析器

```go
import "github.com/cloudwego/eino/components/document/parser"

// 文本解析器
textParser := textparser.New()

// 自定义解析器
type MyParser struct{}

func (p *MyParser) Parse(ctx context.Context, reader io.Reader) ([]*schema.Document, error) {
    data, _ := io.ReadAll(reader)
    return []*schema.Document{
        {
            Content:  string(data),
            MetaData: map[string]any{"source": "my_parser"},
        },
    }, nil
}

customParser := customparser.New(&MyParser{})
```

### 8.2 文档结构

```go
// schema.Document
type Document struct {
    Content   string         // 文档内容
    MetaData  map[string]any // 元数据

}
```

```go
import "github.com/cloudwego/eino/components/embedding"
```

## 总结

| 组件 | 核心功能 | 使用场景 |
|------|---------|---------|
| **Model** | LLM 调用 | 对话生成、工具调用 |
| **Tool** | 外部能力 | 搜索、计算、API 调用 |
| **Retriever** | 文档检索 | RAG、知识库 |
| **Prompt** | 模板管理 | 提示词工程 |
| **ABRouter** | 模型路由 | 成本优化、A/B 测试 |
| **Middleware** | 增强工具 | 错误处理、参数修复 |
