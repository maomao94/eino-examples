## 1. 概述

### 1.1 什么是 BatchNode

BatchNode 是 Eino 中用于批量处理数据的节点，支持并行执行多个任务：

```
┌─────────────────────────────────────────────────────────────────┐
│                      BatchNode 工作原理                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  输入: [A, B, C, D, E, F, G, H]                                 │
│         │                                                        │
│         ▼                                                        │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                    BatchNode                             │   │
│  │                                                          │   │
│  │  ┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐                   │   │
│  │  │ W1  │  │ W2  │  │ W3  │  │ W4  │  ← Worker Pool    │   │
│  │  │ A   │  │ B   │  │ C   │  │ D   │                   │   │
│  │  └─────┘  └─────┘  └─────┘  └─────┘                   │   │
│  │        ↓        ↓        ↓        ↓                   │   │
│  │  ┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐                   │   │
│  │  │ W1  │  │ W2  │  │ W3  │  │ W4  │                   │   │
│  │  │ E   │  │ F   │  │ G   │  │ H   │                   │   │
│  │  └─────┘  └─────┘  └─────┘  └─────┘                   │   │
│  │                                                          │   │
│  └─────────────────────────────────────────────────────────┘   │
│         │                                                        │
│         ▼                                                        │
│  输出: [A', B', C', D', E', F', G', H']                          │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 应用场景

| 场景 | 说明 | 优势 |
|------|------|------|
| 批量检索 | 多个查询同时检索 | 提高吞吐量 |
| 批量 Embedding | 多个文本同时向量化 | 降低 API 调用次数 |
| 批量生成 | 批量生成内容 | 提高效率 |
| 数据清洗 | 批量处理数据 | 简化代码 |

### 1.3 与普通节点的区别

| 特性 | 普通 Node | BatchNode |
|------|-----------|-----------|
| 输入类型 | 单个值 | 切片 []T |
| 输出类型 | 单个值 | 切片 []R |
| 执行方式 | 顺序 | 并行 |
| 适用场景 | 单一任务 | 批量任务 |

## 2. BatchNode 基础

### 2.1 基本用法

**功能说明**：创建和使用 BatchNode 处理批量数据

**关键组件**：
- `compose.NewBatchNode`: 创建批处理节点
- `compose.WithMaxConcurrency`: 设置最大并发数

```go
package main

import (
	"context"
	"fmt"
	"time"

	"github.com/cloudwego/eino/compose"
)

// BatchNode 基本使用示例

func main() {
	ctx := context.Background()

	// 1. 创建批处理节点
	batchNode := compose.NewBatchNode[string, string](
		compose.WithNodeName("batch_processor"),
		compose.WithMaxConcurrency(5), // 最多 5 个并发
		compose.WithLambda(func(ctx context.Context, input string) (string, error) {
			// 处理单个输入
			time.Sleep(100 * time.Millisecond) // 模拟处理
			return fmt.Sprintf("处理结果: %s", input), nil
		}),
	)

	// 2. 准备批量输入
	inputs := []string{"A", "B", "C", "D", "E", "F", "G", "H"}

	// 3. 批量执行
	start := time.Now()
	results, err := batchNode.Invoke(ctx, inputs)
	elapsed := time.Since(start)

	if err != nil {
		fmt.Printf("执行失败: %v\n", err)
		return
	}

	// 4. 查看结果
	fmt.Printf("处理 %d 个项目，耗时: %v\n", len(results), elapsed)
	fmt.Println("结果:")
	for i, result := range results {
		fmt.Printf("  %d: %s\n", i+1, result)
	}
}
```

**输出示例**：
```
处理 8 个项目，耗时: 200ms  (8个项目 / 5并发 ≈ 2批)
结果:
  1: 处理结果: A
  2: 处理结果: B
  3: 处理结果: C
  4: 处理结果: D
  5: 处理结果: E
  6: 处理结果: F
  7: 处理结果: G
  8: 处理结果: H
```

## 3. 并行检索

### 3.1 多查询并行检索

**功能说明**：同时执行多个不同的检索任务

```go
package main

import (
	"context"
	"fmt"
	"sync"
	"time"

	"github.com/cloudwego/eino/compose"
	"github.com/cloudwego/eino/schema"
)

// 多 Retriever 并行检索

type ParallelRetrievalSystem struct {
	retrievers map[string]compose.Retriever
}

func NewParallelRetrievalSystem(ctx context.Context) *ParallelRetrievalSystem {
	return &ParallelRetrievalSystem{
		retrievers: map[string]compose.Retriever{
			"knowledge_base": createRetriever(ctx, "kb"),
			"product_db":     createRetriever(ctx, "product"),
			"faq":            createRetriever(ctx, "faq"),
		},
	}
}

func (s *ParallelRetrievalSystem) Retrieve(ctx context.Context, query string) (map[string][]*schema.Text, error) {
	var wg sync.WaitGroup
	var mu sync.Mutex
	results := make(map[string][]*schema.Text)
	errors := make(chan error, len(s.retrievers))

	for name, retriever := range s.retrievers {
		wg.Add(1)
		go func(n string, r compose.Retriever) {
			defer wg.Done()
			docs, err := r.Retrieve(ctx, query)
			if err != nil {
				errors <- fmt.Errorf("%s: %w", n, err)
				return
			}
			mu.Lock()
			results[n] = docs
			mu.Unlock()
		}(name, retriever)
	}

	wg.Wait()
	close(errors)

	// 处理错误
	for err := range errors {
		fmt.Printf("检索错误: %v\n", err)
	}

	return results, nil
}

// 批量多源检索
func (s *ParallelRetrievalSystem) BatchRetrieve(ctx context.Context, queries []string) (map[string]map[string][]*schema.Text, error) {
	var wg sync.WaitGroup
	results := make(map[string]map[string][]*schema.Text)
	lock := &sync.Mutex{}

	for i, query := range queries {
		wg.Add(1)
		go func(idx int, q string) {
			defer wg.Done()

			result, err := s.Retrieve(ctx, q)
			if err != nil {
				return
			}

			lock.Lock()
			results[q] = result
			lock.Unlock()
		}(i, query)
	}

	wg.Wait()
	return results, nil
}
```

### 3.2 分层批量处理

**功能说明**：先批量分类，再批量处理每个类别

```go
package main

import (
	"context"
	"fmt"
)

// 分层批量处理示例

type Document struct {
	ID       string
	Content  string
	Category string
}

type ProcessingResult struct {
	ID      string
	Content string
	Tags    []string
}

// 分层处理流程
func hierarchicalProcess(ctx context.Context, docs []Document) ([]ProcessingResult, error) {
	// 第一层：批量分类
	categorized, err := batchClassify(ctx, docs)
	if err != nil {
		return nil, err
	}

	// 第二层：按类别分组
	groups := groupByCategory(categorized)

	// 第三层：批量处理每个类别
	var results []ProcessingResult
	for category, items := range groups {
		processed, err := batchProcessByCategory(ctx, category, items)
		if err != nil {
			return nil, err
		}
		results = append(results, processed...)
	}

	return results, nil
}

// 批量分类
func batchClassify(ctx context.Context, docs []Document) ([]Document, error) {
	// 使用 BatchNode 并行分类
	batchNode := compose.NewBatchNode[Document, Document](
		compose.WithMaxConcurrency(10),
		compose.WithLambda(func(ctx context.Context, doc Document) (Document, error) {
			// 调用分类模型
			category := classifyDocument(doc.Content)
			doc.Category = category
			return doc, nil
		}),
	)
	return batchNode.Invoke(ctx, docs)
}

// 按类别分组
func groupByCategory(docs []Document) map[string][]Document {
	groups := make(map[string][]Document)
	for _, doc := range docs {
		groups[doc.Category] = append(groups[doc.Category], doc)
	}
	return groups
}

// 按类别批量处理
func batchProcessByCategory(ctx context.Context, category string, docs []Document) ([]ProcessingResult, error) {
	// 根据不同类别使用不同的处理策略
	batchNode := compose.NewBatchNode[Document, ProcessingResult](
		compose.WithMaxConcurrency(5),
		compose.WithLambda(func(ctx context.Context, doc Document) (ProcessingResult, error) {
			return processDocument(doc), nil
		}),
	)
	return batchNode.Invoke(ctx, docs)
}

func classifyDocument(content string) string {
	// 简化分类逻辑
	return "general"
}

func processDocument(doc Document) ProcessingResult {
	// 简化处理逻辑
	return ProcessingResult{
		ID:      doc.ID,
		Content: doc.Content,
		Tags:    []string{"processed"},
	}
}
```

## 4. Worker Pool 模式

### 4.1 自定义 Worker Pool

**功能说明**：实现一个可复用的 Worker Pool

```go
package main

import (
	"context"
	"fmt"
	"sync"
)

// WorkerPool 工作池模式

type WorkerPool[T any, R any] struct {
	workers    int
	taskFunc   func(ctx context.Context, task T) (R, error)
	tasks      chan T
	results    chan R
	errors     chan error
	wg         sync.WaitGroup
	ctx        context.Context
	cancel     context.CancelFunc
}

func NewWorkerPool[T any, R any](
	workers int,
	taskFunc func(ctx context.Context, task T) (R, error),
) *WorkerPool[T, R] {
	return &WorkerPool[T, R]{
		workers:  workers,
		taskFunc: taskFunc,
		tasks:    make(chan T, workers*2),
		results:  make(chan R, workers*2),
		errors:   make(chan error, workers*2),
	}
}

func (p *WorkerPool[T, R]) Start(ctx context.Context) {
	p.ctx, p.cancel = context.WithCancel(ctx)

	for i := 0; i < p.workers; i++ {
		p.wg.Add(1)
		go p.worker(i)
	}
}

func (p *WorkerPool[T, R]) worker(id int) {
	defer p.wg.Done()

	for {
		select {
		case <-p.ctx.Done():
			return
		case task, ok := <-p.tasks:
			if !ok {
				return
			}
			result, err := p.taskFunc(p.ctx, task)
			if err != nil {
				select {
				case p.errors <- err:
				case <-p.ctx.Done():
					return
				}
			} else {
				select {
				case p.results <- result:
				case <-p.ctx.Done():
					return
				}
			}
		}
	}
}

func (p *WorkerPool[T, R]) Submit(task T) {
	p.tasks <- task
}

func (p *WorkerPool[T, R]) SubmitAndWait(tasks []T) ([]R, []error) {
	// 提交所有任务
	for _, task := range tasks {
		p.Submit(task)
	}

	var results []R
	var errors []error

	// 等待所有任务完成
	for i := 0; i < len(tasks); i++ {
		select {
		case result := <-p.results:
			results = append(results, result)
		case err := <-p.errors:
			errors = append(errors, err)
		}
	}

	return results, errors
}

func (p *WorkerPool[T, R]) Stop() {
	p.cancel()
	close(p.tasks)
	p.wg.Wait()
	close(p.results)
	close(p.errors)
}

// 使用示例
func main() {
	ctx := context.Background()

	// 创建 Worker Pool
	pool := NewWorkerPool[string, int](
		10, // 10 个 worker
		func(ctx context.Context, task string) (int, error) {
			// 模拟处理
			return len(task), nil
		},
	)

	// 启动
	pool.Start(ctx)

	// 提交任务
	tasks := []string{"apple", "banana", "cherry", "date", "elderberry"}
	results, errors := pool.SubmitAndWait(tasks)

	// 停止
	pool.Stop()

	// 查看结果
	fmt.Printf("处理了 %d 个任务\n", len(results))
	fmt.Printf("有 %d 个错误\n", len(errors))
	for i, r := range results {
		fmt.Printf("  任务 %d: 结果=%d\n", i+1, r)
	}
}
```

### 4.2 带优先级的 Worker Pool

**功能说明**：支持优先级处理的 Worker Pool

```go
package main

import (
	"container/heap"
	"context"
	"fmt"
	"sync"
)

// PriorityWorkerPool 带优先级的 Worker Pool

type PriorityTask struct {
	Priority int
	Task     interface{}
	index    int // 用于 heap 接口
}

type PriorityQueue []*PriorityTask

func (pq PriorityQueue) Len() int { return len(pq) }

func (pq PriorityQueue) Less(i, j int) bool {
	return pq[i].Priority > pq[j].Priority // 优先级高的先处理
}

func (pq PriorityQueue) Swap(i, j int) {
	pq[i], pq[j] = pq[i], pq[j]
	pq[i].index = i
	pq[j].index = j
}

func (pq *PriorityQueue) Push(x any) {
	n := len(*pq)
	task := x.(*PriorityTask)
	task.index = n
	*pq = append(*pq, task)
}

func (pq *PriorityQueue) Pop() any {
	old := *pq
	n := len(old)
	task := old[n-1]
	old[n-1] = nil
	*pq = old[0 : n-1]
	return task
}

type PriorityWorkerPool struct {
	workers    int
	taskFunc   func(ctx context.Context, task interface{}) (interface{}, error)
	taskQueue  *PriorityQueue
	taskLock   sync.Mutex
	taskCond   *sync.Cond
	results    chan interface{}
	errors     chan error
	wg         sync.WaitGroup
	ctx        context.Context
	cancel     context.CancelFunc
	running    bool
}

func NewPriorityWorkerPool(
	workers int,
	taskFunc func(ctx context.Context, task interface{}) (interface{}, error),
) *PriorityWorkerPool {
	pq := make(PriorityQueue, 0)
	heap.Init(&pq)

	pool := &PriorityWorkerPool{
		workers:   workers,
		taskFunc:  taskFunc,
		taskQueue: &pq,
		results:   make(chan interface{}, workers*2),
		errors:    make(chan error, workers*2),
	}
	pool.taskCond = sync.NewCond(&pool.taskLock)
	return pool
}

func (p *PriorityWorkerPool) Start(ctx context.Context) {
	p.ctx, p.cancel = context.WithCancel(ctx)
	p.running = true

	for i := 0; i < p.workers; i++ {
		p.wg.Add(1)
		go p.worker()
	}
}

func (p *PriorityWorkerPool) worker() {
	defer p.wg.Done()

	for {
		p.taskLock.Lock()
		for p.taskQueue.Len() == 0 {
			if !p.running {
				p.taskLock.Unlock()
				return
			}
			p.taskCond.Wait()
		}
		task := heap.Pop(p.taskQueue).(*PriorityTask)
		p.taskLock.Unlock()

		result, err := p.taskFunc(p.ctx, task.Task)
		if err != nil {
			p.errors <- err
		} else {
			p.results <- result
		}
	}
}

func (p *PriorityWorkerPool) Submit(priority int, task interface{}) {
	p.taskLock.Lock()
	defer p.taskLock.Unlock()
	heap.Push(p.taskQueue, &PriorityTask{
		Priority: priority,
		Task:     task,
	})
	p.taskCond.Signal()
}

func (p *PriorityWorkerPool) Stop() {
	p.taskLock.Lock()
	p.running = false
	p.taskCond.Broadcast()
	p.taskLock.Unlock()
	p.wg.Wait()
	close(p.results)
	close(p.errors)
}
```

## 5. 错误处理与重试

### 5.1 批量重试机制

**功能说明**：自动重试失败的批量任务

```go
package main

import (
	"context"
	"fmt"
	"math"
	"time"

	"github.com/cloudwego/eino/compose"
)

// 带重试的批量处理

type RetryConfig struct {
	MaxRetries    int
	BaseDelay     time.Duration
	MaxDelay      time.Duration
	RetryableFunc func(error) bool
}

func WithRetry[T any, R any](
	fn func(ctx context.Context, input T) (R, error),
	config RetryConfig,
) func(ctx context.Context, input T) (R, error) {
	return func(ctx context.Context, input T) (R, error) {
		var lastErr error

		for attempt := 0; attempt <= config.MaxRetries; attempt++ {
			result, err := fn(ctx, input)
			if err == nil {
				return result, nil
			}

			lastErr = err

			// 检查是否可重试
			if config.RetryableFunc != nil && !config.RetryableFunc(err) {
				break
			}

			// 计算延迟（指数退避）
			if attempt < config.MaxRetries {
				delay := float64(config.BaseDelay) * math.Pow(2, float64(attempt))
				if delay > float64(config.MaxDelay) {
					delay = float64(config.MaxDelay)
				}

				select {
				case <-time.After(time.Duration(delay)):
				case <-ctx.Done():
					return *new(R), ctx.Err()
				}
			}
		}

		return *new(R), fmt.Errorf("超过最大重试次数: %w", lastErr)
	}
}

// 批量执行带重试
func BatchWithRetry[T any, R any](
	ctx context.Context,
	inputs []T,
	fn func(ctx context.Context, input T) (R, error),
	workers int,
	config RetryConfig,
) ([]R, []error) {
	// 创建带重试的函数
	retryFn := WithRetry(fn, config)

	// 创建 BatchNode
	node := compose.NewBatchNode[T, R](
		compose.WithMaxConcurrency(workers),
		compose.WithLambda(retryFn),
	)

	// 执行
	results, err := node.Invoke(ctx, inputs)

	// 分类结果和错误
	var okResults []R
	var errors []error

	for i, r := range results {
		if err[i] != nil {
			errors = append(errors, fmt.Errorf("任务 %d: %w", i, err[i]))
		} else {
			okResults = append(okResults, r)
		}
	}

	return okResults, errors
}
```

### 5.2 部分失败处理

**功能说明**：处理批量任务中的部分失败

```go
package main

import (
	"context"
	"fmt"

	"github.com/cloudwego/eino/compose"
)

// 部分失败处理策略

type PartialResult[T any] struct {
	Results []T
	Failed  []FailedItem
}

type FailedItem struct {
	Index int
	Input interface{}
	Error error
}

func BatchWithPartialFailure[T any, R any](
	ctx context.Context,
	inputs []T,
	fn func(ctx context.Context, input T) (R, error),
	workers int,
) *PartialResult[R] {
	node := compose.NewBatchNode[T, R](
		compose.WithMaxConcurrency(workers),
		compose.WithLambda(func(ctx context.Context, input T) (R, error) {
			return fn(ctx, input)
		}),
	)

	results, errs := node.Invoke(ctx, inputs)

	partial := &PartialResult[R]{
		Results: make([]R, 0, len(results)),
		Failed:  make([]FailedItem, 0),
	}

	for i, result := range results {
		if errs[i] != nil {
			partial.Failed = append(partial.Failed, FailedItem{
				Index: i,
				Input: inputs[i],
				Error: errs[i],
			})
		} else {
			partial.Results = append(partial.Results, result)
		}
	}

	return partial
}

// 使用示例
func main() {
	ctx := context.Background()
	inputs := []int{1, 2, 3, 4, 5}

	partial := BatchWithPartialFailure(ctx, inputs, func(ctx context.Context, input int) (int, error) {
		if input == 3 {
			return 0, fmt.Errorf("模拟错误")
		}
		return input * 2, nil
	}, 3)

	fmt.Printf("成功: %d 个\n", len(partial.Results))
	fmt.Printf("失败: %d 个\n", len(partial.Failed))
	for _, f := range partial.Failed {
		fmt.Printf("  索引 %d: %v\n", f.Index, f.Error)
	}
}
```

## 6. 性能优化

### 6.1 批量大小选择

**原则**：

| 因素 | 建议 |
|------|------|
| API 限流 | 减小并发，增加批次 |
| 内存限制 | 减小每批大小 |
| 网络延迟 | 增加并发 |
| 成功率 | 适中批次大小 |

### 6.2 缓存优化

```go
package main

import (
	"context"
	"sync"

	"github.com/cloudwego/eino/compose"
)

// 带缓存的批量处理

type Cache[K comparable, V any] struct {
	data map[K]V
	lock sync.RWMutex
}

func NewCache[K comparable, V any]() *Cache[K, V] {
	return &Cache[K, V]{
		data: make(map[K]V),
	}
}

func (c *Cache[K, V]) Get(key K) (V, bool) {
	c.lock.RLock()
	defer c.lock.RUnlock()
	v, ok := c.data[key]
	return v, ok
}

func (c *Cache[K, V]) Set(key K, value V) {
	c.lock.Lock()
	defer c.lock.Unlock()
	c.data[key] = value
}

// 使用缓存的批量检索
func BatchRetrieveWithCache(
	ctx context.Context,
	queries []string,
	cache *Cache[string, string],
	fn func(ctx context.Context, query string) (string, error),
) ([]string, []error) {
	node := compose.NewBatchNode[string, string](
		compose.WithMaxConcurrency(10),
		compose.WithLambda(func(ctx context.Context, query string) (string, error) {
			// 先检查缓存
			if cached, ok := cache.Get(query); ok {
				return cached, nil
			}
			// 执行检索
			result, err := fn(ctx, query)
			if err != nil {
				return "", err
			}
			// 写入缓存
			cache.Set(query, result)
			return result, nil
		}),
	)

	results, errs := node.Invoke(ctx, queries)
	return results, errs
}
```

### 6.3 预热策略

```go
package main

import (
	"context"
	"time"

	"github.com/cloudwego/eino/compose"
)

// 模型预热

func Warmup(ctx context.Context, node *compose.Graph) error {
	// 执行一个预热请求
	_, err := node.Invoke(ctx, "预热请求")
	return err
}

// 带预热的批量处理
func BatchProcessWithWarmup[T any, R any](
	ctx context.Context,
	inputs []T,
	fn func(ctx context.Context, input T) (R, error),
	workers int,
) ([]R, []error) {
	// 创建节点
	node := compose.NewBatchNode[T, R](
		compose.WithMaxConcurrency(workers),
		compose.WithLambda(fn),
	)

	// 预热
	warmupCtx, cancel := context.WithTimeout(ctx, 30*time.Second)
	defer cancel()

	// 执行一次预热
	node.Invoke(warmupCtx, []T{inputs[0]})

	// 正式处理
	return node.Invoke(ctx, inputs)
}
```

## 7. 常见问题

### Q1: 并发数设置多少合适？

**建议**：
- API 调用：查看服务限流，一般 5-20
- 本地处理：CPU 核心数的 2-4 倍
- I/O 密集：可以更高（20-50）

### Q2: 内存占用过高？

**可能原因**：
- 批量太大
- 结果累积未及时处理

**解决方案**：
```go
// 分批处理
batchSize := 100
for i := 0; i < len(inputs); i += batchSize {
    batch := inputs[i:min(i+batchSize, len(inputs))]
    results, _ := node.Invoke(ctx, batch)
    // 及时处理 results
}
```

### Q3: 如何处理超时？

**解决方案**：
```go
// 使用带超时的 context
for _, input := range inputs {
    ctx := context.WithTimeout(originalCtx, 10*time.Second)
    go func(ctx context.Context, in T) {
        result, _ := node.Invoke(ctx, []T{in})
    }(ctx)
}
```
