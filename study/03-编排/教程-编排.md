## 1. Compose 概述

### 1.1 什么是 Compose

Compose 是 Eino 的编排层，负责将多个组件（Model、Tool、Retriever 等）组合成复杂的应用。

```
┌─────────────────────────────────────────────────────────────┐
│                       Compose                               │
│                                                              │
│  ┌─────────┐    ┌─────────┐    ┌─────────┐                │
│  │  Node A  │───▶│  Node B  │───▶│  Node C  │                │
│  └─────────┘    └─────────┘    └─────────┘                │
│                                                              │
│  ┌─────────────────────────────────────────────────────┐   │
│  │              编排方式                                │   │
│  │  - Graph: 节点+边，隐式依赖                         │   │
│  │  - Workflow: 声明式，显式字段映射                   │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 核心概念

| 概念 | 说明 |
|------|------|
| **Node（节点）** | 基本执行单元，如 Lambda、Model、Tool |
| **Edge（边）** | 节点之间的连接，表示执行顺序 |
| **Graph（图）** | 由节点和边组成的有向无环图（DAG） |
| **Workflow（工作流）** | 声明式的节点组合，支持字段映射 |

### 1.3 目录结构

```
compose/
├── graph/                    # DAG 图编排
│   ├── simple/              # 简单示例
│   ├── state/              # 带状态的 Graph
│   ├── async_node/         # 异步节点
│   ├── tool_call_agent/    # 工具调用
│   └── react_with_interrupt/ # 中断处理
├── workflow/                # 声明式工作流
│   ├── 1_simple/           # 最简单示例
│   ├── 2_field_mapping/    # 字段映射
│   ├── 3_data_only/        # 仅数据传递
│   ├── 4_control_only/     # 仅控制依赖
│   ├── 5_static_values/    # 静态值
│   └── 6_stream_field_map/ # 流式字段映射
└── batch/                   # 批处理
    └── batch/               # BatchNode
```

## 2. Lambda 函数类型

### 2.1 三种 Lambda 类型

Compose 提供了三种 Lambda 函数，用于定义节点的行为：

```go
// 1. InvokableLambda - 普通函数，输入输出都是值
compose.InvokableLambda(func(ctx context.Context, in string) (string, error) {
    return strings.ToUpper(in), nil
})

// 2. StreamableLambda - 流式函数，输出是流
compose.StreamableLambda(func(ctx context.Context, in string) (*schema.StreamReader[string], error) {
    sr, sw := schema.Pipe[string](10)
    go func() {
        for _, ch := range in {
            sw.Send(string(ch), nil)
        }
        sw.Close()
    }()
    return sr, nil
})

// 3. TransformableLambda - 转换函数，输入输出都是流
compose.TransformableLambda(func(ctx context.Context, in *schema.StreamReader[string]) (
    *schema.StreamReader[string], error) {
    sr, sw := schema.Pipe[string](10)
    go func() {
        for {
            chunk, err := in.Recv()
            if err == io.EOF { break }
            sw.Send(strings.ToUpper(chunk), nil)
        }
        sw.Close()
    }()
    return sr, nil
})
```

### 2.2 类型对比

| 类型 | 输入 | 输出 | 适用场景 |
|------|------|------|---------|
| `InvokableLambda` | 值 | 值 | 同步处理，批量操作 |
| `StreamableLambda` | 值 | 流 | 打字机效果，长文本生成 |
| `TransformableLambda` | 流 | 流 | 流式转换，数据管道 |

### 2.3 使用示例

```go
// InvokableLambda - 同步处理
upperCase := compose.InvokableLambda(func(ctx context.Context, in string) (string, error) {
    return strings.ToUpper(in), nil
})

// StreamableLambda - 流式输出
streamingUpperCase := compose.StreamableLambda(func(ctx context.Context, in string) (*schema.StreamReader[string], error) {
    sr, sw := schema.Pipe[string](len(in))
    go func() {
        for _, ch := range in {
            sw.Send(strings.ToUpper(string(ch)), nil)
        }
        sw.Close()
    }()
    return sr, nil
})

// TransformableLambda - 流式转换
addPrefix := compose.TransformableLambda(func(ctx context.Context, in *schema.StreamReader[string]) (*schema.StreamReader[string], error) {
    sr, sw := schema.Pipe[string](10)
    go func() {
        sw.Send("[PREFIX] ", nil)
        for {
            chunk, err := in.Recv()
            if err == io.EOF { break }
            sw.Send(chunk, nil)
        }
        sw.Close()
    }()
    return sr, nil
})
```

## 3. Graph DAG 编排

### 3.1 什么是 Graph

Graph 是有向无环图（DAG），通过节点和边来定义执行流程。

```
START ──▶ [Prompt] ──▶ [Model] ──▶ END
              │           │
              │           ▼
              │        [Tool Call]
              │           │
              ▼           ▼
           [Result] ◀──[Output]
```

### 3.2 基本使用

```go
// 创建 Graph，指定输入输出类型
g := compose.NewGraph[map[string]any, *schema.Message]()

// 添加节点
_ = g.AddChatTemplateNode("prompt", promptTemplate)  // 聊天模板
_ = g.AddChatModelNode("model", chatModel)           // 聊天模型

// 添加边（连接节点）
_ = g.AddEdge(compose.START, "prompt")   // START → prompt
_ = g.AddEdge("prompt", "model")          // prompt → model
_ = g.AddEdge("model", compose.END)      // model → END

// 编译
runnable, err := g.Compile(ctx,
    compose.WithGraphName("SimpleGraph"),
    compose.WithMaxRunSteps(10),
)

// 调用
result, err := runnable.Invoke(ctx, input)
```

### 3.3 节点类型

```go
// Lambda 节点
_ = g.AddLambdaNode("my_lambda", compose.InvokableLambda(myFunc))

// ChatModel 节点
_ = g.AddChatModelNode("chat_model", chatModel)

// ChatTemplate 节点
_ = g.AddChatTemplateNode("template", promptTemplate)

// Tools 节点
_ = g.AddToolsNode("tools", toolNode)

// Graph 节点（嵌套子图）
_ = g.AddGraphNode("sub_graph", subRunnable)

// ToList 节点（转换为列表）
_ = g.AddLambdaNode("to_list", compose.ToList[string]())
```

### 3.4 完整示例

```go
func main() {
    ctx := context.Background()

    // 创建 Graph
    g := compose.NewGraph[map[string]any, *schema.Message]()

    // 创建 Prompt 模板
    pt := prompt.FromMessages(
        schema.FString,
        schema.UserMessage("北京的天气怎么样？城市：{city}"),
    )

    // 添加节点
    _ = g.AddChatTemplateNode("prompt", pt)
    _ = g.AddChatModelNode("model", &mockChatModel{}, compose.WithNodeName("ChatModel"))

    // 添加边
    _ = g.AddEdge(compose.START, "prompt")
    _ = g.AddEdge("prompt", "model")
    _ = g.AddEdge("model", compose.END)

    // 编译
    run, err := g.Compile(ctx,
        compose.WithMaxRunSteps(10),
        compose.WithGraphName("WeatherGraph"),
    )
    if err != nil {
        panic(err)
    }

    // 调用
    in := map[string]any{"city": "北京"}
    result, err := run.Invoke(ctx, in)
    fmt.Println("Result:", result.Content)

    // 流式调用
    stream, err := run.Stream(ctx, in)
    defer stream.Close()
    for {
        chunk, err := stream.Recv()
        if err == io.EOF { break }
        fmt.Print(chunk.Content)
    }
}

// Mock ChatModel 实现
type mockChatModel struct{}
func (m *mockChatModel) Generate(ctx context.Context, input []*schema.Message, opts ...model.Option) (*schema.Message, error) {
    return schema.AssistantMessage("北京今天天气晴朗，气温 25 度", nil), nil
}
func (m *mockChatModel) Stream(ctx context.Context, input []*schema.Message, opts ...model.Option) (*schema.StreamReader[*schema.Message], error) {
    sr, sw := schema.Pipe[*schema.Message](0)
    go func() {
        defer sw.Close()
        sw.Send(schema.AssistantMessage("北京今天天气晴朗，", nil), nil)
        sw.Send(schema.AssistantMessage("气温 25 度", nil), nil)
    }()
    return sr, nil
}
func (m *mockChatModel) BindTools(tools []*schema.ToolInfo) error { return nil }
```

## 4. Workflow 声明式工作流

### 4.1 什么是 Workflow

Workflow 是声明式的编排方式，通过字段映射来指定数据如何传递。

```
┌─────────────────────────────────────────────────────────────┐
│                    Workflow 声明式                            │
│                                                              │
│  输入 ──┬──▶ 节点 A ──▶ 节点 B ──▶ 输出                      │
│         │        │          │                               │
│         │        ▼          ▼                               │
│         │     [field1]   [result]                           │
│         │                                      
│         └───────────────────────────────────▶ [static_value] │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 基本使用

```go
// 创建 Workflow
wf := compose.NewWorkflow[int, string]()

// 添加 Lambda 节点，同时指定输入来源
wf.AddLambdaNode("lambda", compose.InvokableLambda(
    func(ctx context.Context, in int) (string, error) {
        return strconv.Itoa(in), nil
    },
)).AddInput(compose.START)  // 从 START 获取输入

// 设置 END 的输入
wf.End().AddInput("lambda")  // 从 lambda 获取输出

// 编译和调用
run, err := wf.Compile(ctx)
result, err := run.Invoke(ctx, 42)  // 输入 42，输出 "42"
```

### 4.3 字段映射

Workflow 的核心功能是字段映射：

```go
type Input struct {
    Message struct {
        Content string `json:"content"`
    } `json:"message"`
    Query string `json:"query"`
}

type Counter struct {
    FullStr string `json:"full_str"`
    SubStr  string `json:"sub_str"`
}

// 创建 Workflow
wf := compose.NewWorkflow[Input, map[string]any]()

// 添加节点，指定字段映射
wf.AddLambdaNode("counter", compose.InvokableLambda(wordCounter)).
    AddInput(compose.START,
        // MapFields: 简单字段映射
        // START 的 SubStr → counter 的 SubStr
        compose.MapFields("Query", "SubStr"),
        // MapFieldPaths: 嵌套字段映射
        // START.Message.Content → counter.FullStr
        compose.MapFieldPaths([]string{"Message", "Content"}, []string{"FullStr"}),
    )

// 设置输出
wf.End().
    AddInput("counter", compose.ToField("count"))  // counter 的输出 → result["count"]
```

### 4.4 静态值

Workflow 支持设置静态值（不依赖上游输出）：

```go
wf.AddLambdaNode("processor", compose.InvokableLambda(process)).
    AddInput("upstream", compose.MapFields("result", "input")).
    AddStaticValue("config", map[string]any{  // 静态配置
        "timeout": 30,
        "retries": 3,
    })
```

### 4.5 完整示例：字段映射

```go
package main

// 演示字段映射能力
func main() {
    ctx := context.Background()

    // 定义输入类型
    type message struct {
        *schema.Message                  // 嵌套消息
        SubStr string `json:"sub_str"`   // 查询字符串
    }

    // 单词计数器
    wordCounter := compose.InvokableLambda(func(ctx context.Context, c counter) (int, error) {
        return strings.Count(c.FullStr, c.SubStr), nil
    })

    // 创建 Workflow
    wf := compose.NewWorkflow[message, map[string]any]()

    // 节点 c1：统计 Content 中的 SubStr
    wf.AddLambdaNode("c1", wordCounter).
        AddInput(compose.START,
            compose.MapFields("SubStr", "SubStr"),                           // 简单映射
            compose.MapFieldPaths([]string{"Message", "Content"}, []string{"FullStr"}), // 嵌套映射
        )

    // 节点 c2：统计 ReasoningContent 中的 SubStr
    wf.AddLambdaNode("c2", wordCounter).
        AddInput(compose.START,
            compose.MapFields("SubStr", "SubStr"),
            compose.MapFieldPaths([]string{"Message", "ReasoningContent"}, []string{"FullStr"}),
        )

    // 输出映射
    wf.End().
        AddInput("c1", compose.ToField("content_count")).
        AddInput("c2", compose.ToField("reasoning_count"))

    // 编译
    run, err := wf.Compile(ctx)
    if err != nil {
        panic(err)
    }

    // 调用
    result, err := run.Invoke(ctx, message{
        Message: &schema.Message{
            Content:          "Hello world! Hello Go!",
            ReasoningContent: "I need to say hello to Go",
        },
        SubStr: "Hello",
    })
    // 结果: {"content_count": 2, "reasoning_count": 1}
}
```

## 5. Graph vs Workflow 对比

### 5.1 核心区别

| 特性 | Graph | Workflow |
|------|-------|----------|
| **依赖方式** | 隐式（按边顺序） | 显式（字段映射） |
| **数据传递** | 整个输出传递 | 可指定字段 |
| **静态值** | 不支持 | 支持 |
| **适用场景** | 简单流程 | 复杂数据转换 |

### 5.2 选择建议

```
选择 Graph：
├── 流程简单，节点顺序明确
├── 不需要复杂的字段映射
└── 示例：Prompt → Model → Output

选择 Workflow：
├── 数据需要在节点间转换
├── 需要指定静态配置
├── 多输入/多输出场景
└── 示例：多个数据源 → 合并处理 → 格式化输出
```

### 5.3 转换示例

```go
// Graph 写法
g := compose.NewGraph[string, string]()
g.AddLambdaNode("upper", compose.InvokableLambda(strings.ToUpper))
g.AddEdge(compose.START, "upper")
g.AddEdge("upper", compose.END)

// Workflow 等价写法
wf := compose.NewWorkflow[string, string]()
wf.AddLambdaNode("upper", compose.InvokableLambda(strings.ToUpper)).
    AddInput(compose.START)
wf.End().AddInput("upper")
```

## 6. 节点类型详解

### 6.1 LambdaNode

```go
// 添加 Lambda 节点
g.AddLambdaNode("my_lambda", compose.InvokableLambda(func(ctx context.Context, in string) (string, error) {
```

```go
g.AddChatModelNode("chat_model", chatModel,
```

## 7. 边和分支

### 7.1 普通边

```go
// 顺序连接
g.AddEdge(compose.START, "node_a")
g.AddEdge("node_a", "node_b")
g.AddEdge("node_b", compose.END)
```

### 7.2 条件分支

```go
// 根据输出决定下一个节点
g.AddBranch("router",
    compose.NewGraphBranch(
        // 条件函数：返回下一个节点名称
        func(ctx context.Context, msg *schema.Message) (string, error) {
            if strings.Contains(msg.Content, "搜索") {
                return "search", nil
            }
            return "chat", nil
        },
        // 可能的分支
        map[string]bool{
            "search": true,  // 可以到达 search
            "chat":   true,  // 可以到达 chat
        },
    ),
)
```

### 7.3 流式分支

```go
// 根据流式输出决定分支
g.AddBranch("reviser",
    compose.NewStreamGraphBranch(
        // 流式条件函数
        func(ctx context.Context, sr *schema.StreamReader[*schema.Message]) (string, error) {
            defer sr.Close()

            var content string
            for {
                msg, err := sr.Recv()
                if err == io.EOF { break }
                content += msg.Content

                if strings.Contains(content, "最终答案") {
                    return compose.END, nil
                }
            }
            return "executor", nil
        },
        map[string]bool{
            compose.END:    true,
            "executor":     true,
        },
    ),
)
```

### 7.4 触发模式

```go
// AnyPredecessor：任意前置节点完成即可触发（用于循环图）
g.Compile(ctx,
    compose.WithNodeTriggerMode(compose.AnyPredecessor),
)

// AllPredecessors：所有前置节点完成才触发（默认）
g.Compile(ctx,
    compose.WithNodeTriggerMode(compose.AllPredecessors),
)
```

## 8. 状态管理

### 8.1 状态类型定义

```go
type myState struct {
    Messages []string      // 消息历史
    Counter  int           // 计数器
    Context  map[string]any // 上下文数据
}
```

### 8.2 状态初始化

```go
// 创建带状态的 Graph
sg := compose.NewGraph[string, string](
    compose.WithGenLocalState(func(ctx context.Context) *myState {
        return &myState{
            Messages: make([]string, 0),
            Counter:  0,
        }
    }),
)
```

### 8.3 StatePreHandler 和 StatePostHandler

```go
// 前置处理：节点执行前，更新状态
preHandler := func(ctx context.Context, input string, state *myState) (string, error) {
    state.Messages = append(state.Messages, "Input: "+input)
    state.Counter++
    return input, nil
}

// 后置处理：节点执行后，更新状态
postHandler := func(ctx context.Context, output string, state *myState) (string, error) {
    state.Messages = append(state.Messages, "Output: "+output)
    return output, nil
}

// 添加节点时指定处理器
g.AddLambdaNode("processor", myLambda,
    compose.WithStatePreHandler(preHandler),
    compose.WithStatePostHandler(postHandler),
)
```

### 8.4 完整示例

```go
type testState struct {
    History []string
}

sg := compose.NewGraph[string, string](
    compose.WithGenLocalState(func(ctx context.Context) *testState {
        return &testState{}
    }),
)

// 记录输入
l1Pre := func(ctx context.Context, in string, state *testState) (string, error) {
    state.History = append(state.History, "IN: "+in)
    return in, nil
}

// 处理
l1 := compose.InvokableLambda(func(ctx context.Context, in string) (string, error) {
    return "Result: " + in, nil
})

// 记录输出
l1Post := func(ctx context.Context, out string, state *testState) (string, error) {
    state.History = append(state.History, "OUT: "+out)
    return out, nil
}

sg.AddLambdaNode("process", l1,
    compose.WithStatePreHandler(l1Pre),
    compose.WithStatePostHandler(l1Post),
)
sg.AddEdge(compose.START, "process")
sg.AddEdge("process", compose.END)

run, _ := sg.Compile(ctx)
result, _ := run.Invoke(ctx, "hello")

// 状态中保存了执行历史
// state.History = ["IN: hello", "OUT: Result: hello"]
```

## 9. BatchNode 批处理

### 9.1 概述

BatchNode 用于批量处理数据，支持并发控制和断点恢复。

### 9.2 基本使用

```go
// 定义任务
type ReviewRequest struct {
    DocumentID string
    Content    string
    Priority   string
}

type ReviewResult struct {
    DocumentID string
    Approved  bool
    Score     float64
}

// 创建批处理节点
batchNode := batch.NewBatchNode(&batch.NodeConfig[ReviewRequest, ReviewResult]{
    Name:           "BatchReviewer",
    InnerTask:      reviewWorkflow,  // 内部 Workflow
    MaxConcurrency: 3,              // 最大并发数
})

// 批量调用
docs := []ReviewRequest{
    {DocumentID: "DOC-001", Content: "内容1", Priority: "high"},
    {DocumentID: "DOC-002", Content: "内容2", Priority: "low"},
    {DocumentID: "DOC-003", Content: "内容3", Priority: "medium"},
}

results, err := batchNode.Invoke(ctx, docs)
```

### 9.3 编译选项

```go
batchNode := batch.NewBatchNode(&batch.NodeConfig[ReviewRequest, ReviewResult]{
    Name:      "NamedBatch",
    InnerTask: innerWorkflow,
    MaxConcurrency: 5,

    // 内部 Workflow 的编译选项
    InnerCompileOptions: []compose.GraphCompileOption{
        compose.WithGraphName("SingleDocWorkflow"),
        compose.WithMaxRunSteps(10),
    },
})
```

### 9.4 调用选项

```go
// 回调处理
handler := callbacks.NewHandlerBuilder().
    OnStartFn(func(ctx context.Context, info *callbacks.RunInfo, input callbacks.CallbackInput) context.Context {
        fmt.Printf("开始: %s/%s\n", info.Component, info.Name)
        return ctx
    }).
    OnEndFn(func(ctx context.Context, info *callbacks.RunInfo, output callbacks.CallbackOutput) context.Context {
        fmt.Printf("完成: %s/%s\n", info.Component, info.Name)
        return ctx
    }).
    Build()

// 传入回调
ctxWithCallback := callbacks.InitCallbacks(ctx, nil, handler)
results, err := batchNode.Invoke(ctxWithCallback, docs,
    batch.WithInnerOptions(compose.WithCallbacks(myCallback)),
)
```

### 9.5 断点恢复

```go
// 检查点存储
store := newMemoryCheckpointStore()

// 编译时配置检查点
runner, err := parentGraph.Compile(ctx,
    compose.WithCheckPointStore(store),
)

// 第一次调用（可能中断）
checkpointID := "batch-001"
results, err := runner.Invoke(ctx, docs, compose.WithCheckPointID(checkpointID))

if err != nil {
    // 提取中断信息
    info, ok := compose.ExtractInterruptInfo(err)
    if ok {
        // 准备恢复数据
        resumeData := make(map[string]any)
        for _, iCtx := range info.InterruptContexts {
            resumeData[iCtx.ID] = myDecision
        }

        // 恢复执行
        resumeCtx := compose.BatchResumeWithData(ctx, resumeData)
        results, err = runner.Invoke(resumeCtx, nil, compose.WithCheckPointID(checkpointID))
    }
}
```

```go
func BuildRAGPipeline(ctx context.Context) (*compose.Workflow, error) {
    wf := compose.NewWorkflow[string, string]()

    // 1. 检索节点
    retriever := createRetriever()

    // 2. 构造 Prompt
    pt := prompt.FromMessages(
        schema.FString,
        schema.SystemMessage("基于以下资料回答问题。资料：{context}"),
        schema.UserMessage("问题：{question}"),
    )

    // 3. 生成回答
    chatModel := createChatModel()

    // 添加节点
    wf.AddLambdaNode("retrieve", compose.InvokableLambda(
        func(ctx context.Context, query string) ([]string, error) {
            return retriever.Retrieve(ctx, query)
        },
    )).AddInput(compose.START, compose.MapFields("", ""))

    wf.AddChatTemplateNode("prompt", pt,
        compose.WithStatePreHandler(func(ctx context.Context, in []string, state any) ([]*schema.Message, error) {
            return []*schema.Message{
                schema.SystemMessage(fmt.Sprintf("基于以下资料回答：\n%s", strings.Join(in, "\n"))),
            }, nil
        }),
    ).AddInput("retrieve", compose.ToField("context"))

    wf.AddChatModelNode("generate", chatModel).
        AddInput("prompt")

    wf.End().AddInput("generate")

    return wf.Compile(ctx)
}
```

```go
func BuildRouterPipeline(ctx context.Context) (*compose.Graph, error) {
    g := compose.NewGraph[string, string]()

    // 路由函数
    router := compose.NewGraphBranch(
        func(ctx context.Context, query string) (string, error) {
            if strings.Contains(query, "代码") {
                return "coder", nil
            }
            if strings.Contains(query, "搜索") {
                return "searcher", nil
            }
            return "chat", nil
        },
        map[string]bool{"coder": true, "searcher": true, "chat": true},
    )

    g.AddLambdaNode("router", compose.InvokableLambda(func(s string) (string, error) {
        return s, nil
    }))

    g.AddLambdaNode("coder", compose.InvokableLambda(codeHelper))
    g.AddLambdaNode("searcher", compose.InvokableLambda(webSearch))
    g.AddLambdaNode("chat", compose.InvokableLambda(chatHelper))

    g.AddEdge(compose.START, "router")
    g.AddBranch("router", router)
    g.AddEdge("coder", compose.END)
    g.AddEdge("searcher", compose.END)
    g.AddEdge("chat", compose.END)

    return g.Compile(ctx)
}
```

## 总结

| 主题 | 关键点 |
|------|--------|
| **Lambda 类型** | Invokable（同步）、Streamable（流输出）、Transformable（流转换） |
| **Graph** | 节点+边，隐式依赖，适合简单流程 |
| **Workflow** | 声明式，字段映射，适合复杂数据转换 |
| **节点类型** | Lambda、ChatModel、ChatTemplate、Tools、Graph |
| **分支** | GraphBranch（值分支）、StreamGraphBranch（流分支） |
| **状态管理** | StatePreHandler/PostHandler 保存上下文 |
| **BatchNode** | 批量并发处理，支持断点恢复 |
