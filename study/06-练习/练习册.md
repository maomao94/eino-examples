### 练习 1.1: Hello Eino ⭐

**题目**: 创建你的第一个 Eino 程序，调用 ChatModel 输出 "Hello, Eino!"

**要求**:
- 使用 OpenAI 模型
- 打印 AI 的回复

<details>
<summary>答案提示</summary>

```go
// 1. 创建 context
ctx := context.Background()

// 2. 创建模型
model, _ := openai.NewChatModel(ctx, &openai.ChatModelConfig{
    Model:  "gpt-4o-mini",
    APIKey: "your-key",
})

// 3. 构造消息
messages := []*schema.Message{
    schema.UserMessage("说 Hello, Eino!"),
}

// 4. 调用模型
output, _ := model.Generate(ctx, messages)
fmt.Println(output.Content)
```

</details>

### 练习 1.2: 流式输出 ⭐

**题目**: 将练习 1.1 改为流式输出，逐字打印

**要求**:
- 使用 `Stream` 方法
- 不要换行，逐字显示

<details>
<summary>答案提示</summary>

```go
stream, _ := model.Stream(ctx, messages)
defer stream.Close()

for {
    chunk, err := stream.Recv()
    if errors.Is(err, io.EOF) {
        break
    }
    fmt.Print(chunk.Content)  // 不换行
}
```

</details>

### 练习 1.3: 多轮对话 ⭐

**题目**: 实现一个简单的多轮对话程序

**要求**:
- 用户输入 "我叫张三"
- 再问 "我叫什么名字？"
- AI 应该能回答 "张三"

<details>
<summary>答案提示</summary>

```go
messages := []*schema.Message{
    schema.SystemMessage("记住用户告诉你的信息。"),
}

// 第一轮
messages = append(messages, schema.UserMessage("我叫张三"))
resp1, _ := model.Generate(ctx, messages)
fmt.Println("AI:", resp1.Content)

// 第二轮
messages = append(messages, resp1)           // 添加 AI 回复
messages = append(messages, schema.UserMessage("我叫什么名字？"))
resp2, _ := model.Generate(ctx, messages)
fmt.Println("AI:", resp2.Content)
```

### 练习 2.1: 创建计算器工具 ⭐⭐

**题目**: 创建一个计算器工具，支持加减乘除

**要求**:
- 工具名称: `calculator`
- 参数: `a`, `b`, `op`
- 返回计算结果

<details>
<summary>答案提示</summary>

```go
type CalcRequest struct {
    A  int    `json:"a"`
    B  int    `json:"b"`
    Op string `json:"op"`
}

calculatorTool, _ := utils.InferTool(
    "calculator",
    "执行数学计算",
    func(ctx context.Context, req *CalcRequest) (string, error) {
        var result int
        switch req.Op {
        case "add": result = req.A + req.B
        case "sub": result = req.A - req.B
        case "mul": result = req.A * req.B
        case "div": result = req.A / req.B
        }
        return fmt.Sprintf("%d", result), nil
    },
)
```

</details>

### 练习 2.3: 实现 Memory ⭐⭐

**题目**: 实现一个带文件持久化的 Memory

**要求**:
- 保存到 JSONL 文件
- 支持多会话
- 重启后能恢复历史

<details>
<summary>答案提示</summary>

```go
type FileMemory struct {
    mu      sync.RWMutex
    cache   map[string][]*schema.Message
    baseDir string
}

func (m *FileMemory) save(conversationID string) {
    data, _ := json.Marshal(m.cache[conversationID])
    os.WriteFile(
        filepath.Join(m.baseDir, conversationID+".jsonl"),
        data, 0644,
    )
}

func (m *FileMemory) load(conversationID string) {
    data, _ := os.ReadFile(filepath.Join(m.baseDir, conversationID+".jsonl"))
    json.Unmarshal(data, &m.cache[conversationID])
}
```

</details>

### 练习 2.4: Chain 串联 ⭐⭐

**题目**: 创建一个 Chain，实现 "翻译 + 摘要"

**要求**:
- 第一步：翻译成英文
- 第二步：生成简短摘要

<details>
<summary>答案提示</summary>

```go
chain := compose.NewChain[string, string]()

chain.
    AppendLambda(func(ctx, input) (string, error) {
        // 调用翻译模型
        resp, _ := translator.Generate(ctx, []*schema.Message{
            schema.UserMessage("翻译成英文: " + input),
        })
        return resp.Content, nil
    }).
    AppendLambda(func(ctx, input) (string, error) {
        // 调用摘要模型
        resp, _ := summarizer.Generate(ctx, []*schema.Message{
            schema.UserMessage("生成一句话摘要: " + input),
        })
        return resp.Content, nil
    })

result, _ := chain.Compile(ctx).Invoke(ctx, "这是一段很长的文本...")
```

</details>

### 练习 2.5: 带分支的 Graph ⭐⭐⭐

**题目**: 创建一个 Graph，根据问题类型分流

**要求**:
- 分类器判断问题类型（技术/其他）
- 技术问题 → 技术助手
- 其他问题 → 通用助手

<details>
<summary>答案提示</summary>

```go
g := compose.NewGraph[string, string]()

g.AddLambdaNode("classifier", classifyFunc)
g.AddLambdaNode("tech", techFunc)
g.AddLambdaNode("general", generalFunc)

branch := compose.NewGraphBranch(
    func(ctx, type_) (string, error) { return type_, nil },
    map[string]bool{"tech": true, "general": true},
)
g.AddBranch("classifier", branch)
g.AddEdge("tech", compose.END)
g.AddEdge("general", compose.END)
```

</details>

### 练习 3.1: 聊天机器人 ⭐⭐⭐

**题目**: 实现一个完整的聊天机器人

**要求**:
- 支持多轮对话（Memory）
- 支持流式输出
- 支持多个工具调用
- HTTP 接口

<details>
<summary>答案提示</summary>

```go
// 1. 创建 Memory
memory := NewFileMemory("./data")

// 2. 创建 Agent
agent, _ := react.NewAgent(ctx, &react.AgentConfig{
    Model: model,
    ToolsConfig: compose.ToolsNodeConfig{
        Tools: []tool.BaseTool{searchTool, calculatorTool},
    },
})

// 3. HTTP Handler
func chatHandler(c *app.RequestContext) {
    id := c.Query("id")
    msg := c.Query("msg")

    history := memory.GetMessages(id)
    memory.Append(id, schema.UserMessage(msg))

    stream, _ := agent.Stream(ctx, append(history, schema.UserMessage(msg)))

    // SSE 流式返回
    for chunk := range streamChan(stream) {
        c.JSON(200, map[string]string{"content": chunk})
        c.Flush()
    }

    memory.Append(id, schema.AssistantMessage(fullResponse))
}
```

</details>

### 练习 3.2: 循环反思 Agent ⭐⭐⭐

**题目**: 实现一个写作 + 审核的循环 Agent

**要求**:
- Writer 生成内容
- Reviewer 审核并提出意见
- 如果有问题，Writer 改进
- 最多循环 3 次

<details>
<summary>答案提示</summary>

```go
// Writer Agent
writer, _ := adk.NewChatModelAgent(ctx, &adk.ChatModelAgentConfig{
    Name:        "writer",
    Instruction: "根据反馈改进文章",
    Model:       model,
})

// Reviewer Agent
reviewer, _ := adk.NewChatModelAgent(ctx, &adk.ChatModelAgentConfig{
    Name:        "reviewer",
    Instruction: "审核文章，如果有问题提出意见，否则调用 exit",
    Model:       model,
    ToolsConfig: adk.ToolsConfig{
        ToolsNodeConfig: compose.ToolsNodeConfig{
            Tools: []tool.BaseTool{exitTool},
        },
        ReturnDirectly: map[string]bool{"exit": true},
    },
})

// Loop Agent
loop, _ := adk.NewLoopAgent(ctx, &adk.LoopAgentConfig{
    SubAgents:     []adk.Agent{writer, reviewer},
    MaxIterations: 3,
})
```
