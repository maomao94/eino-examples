## 1. Loop Agent（循环反思）

**位置**: `adk/intro/workflow/loop/`

### 1.1 场景说明

Loop Agent 用于需要"执行-评估-改进"循环的场景，比如：
- 写作助手：生成 → 审查 → 修改 → 再审查
- 代码生成：编写 → 测试 → 修复 → 再测试
- 内容创作：初稿 → 反馈 → 优化 → 完成

### 1.2 核心代码

```go
// main.go

func main() {
    ctx := context.Background()

    // 1. 创建循环 Agent
    a, err := adk.NewLoopAgent(ctx, &adk.LoopAgentConfig{
        Name:          "reflection_agent",
        Description:   "Reflection agent with main and critique agent for iterative task solving.",
        SubAgents:     []adk.Agent{
            subagents.NewMainAgent(),      // 执行任务
            subagents.NewCritiqueAgent(),   // 审查结果
        },
        MaxIterations: 5,  // 最多循环5次
    })
    if err != nil {
        log.Fatal(err)
    }

    // 2. 创建 Runner
    runner := adk.NewRunner(ctx, adk.RunnerConfig{
        EnableStreaming: true,
        Agent:           a,
    })

    // 3. 执行查询
    query := "briefly introduce what a multimodal embedding model is."
    iter := runner.Query(ctx, query)

    // 4. 处理事件流
    var lastMessage adk.Message
    for {
        event, ok := iter.Next()
        if !ok {
            break
        }
        if event.Err != nil {
            fmt.Printf("Error: %v\n", event.Err)
            break
        }

        prints.Event(event)
        if event.Output != nil {
            if msg, _, getErr := adk.GetMessage(event); getErr == nil {
                lastMessage = msg
            }
        }
    }
}
```

### 1.4 批评 Agent 实现

```go
func NewCritiqueAgent() adk.Agent {
    // 1. 创建退出工具
    exitAndSummarizeTool, err := utils.InferTool(
        "exit_and_summarize",
        "exit from the loop and provide a final summary response",
        func(ctx context.Context, req *exitAndSummarize) (string, error) {
            // 关键：触发退出循环
            adk.SendToolGenAction(ctx, "exit_and_summarize",
                adk.NewBreakLoopAction("critique_agent"))
            return req.Summary, nil
        })

    // 2. 创建批评 Agent
    a, err := adk.NewChatModelAgent(context.Background(), &adk.ChatModelAgentConfig{
        Name:        "critique_agent",
        Description: "Critique agent that reviews the main agent's work and provides feedback.",
        Instruction: `You are a critique agent responsible for reviewing the main agent's work.
Analyze the provided solution for accuracy, completeness, and quality.
If you find issues or areas for improvement, provide specific feedback.
If the work is satisfactory, call the 'exit_and_summarize' tool and provide a final summary response.`,
        Model: model.NewChatModel(),
        ToolsConfig: adk.ToolsConfig{
            ToolsNodeConfig: compose.ToolsNodeConfig{
                Tools: []tool.BaseTool{
                    exitAndSummarizeTool,
                },
            },
            ReturnDirectly: map[string]bool{
                "exit_and_summarize": true,  // 调用即退出
            },
        },
    })
    return a
}

type exitAndSummarize struct {
    Summary string `json:"summary" jsonschema_description:"final summary of the solution"`
}
```

### 1.6 关键点总结

| 要点 | 说明 |
|------|------|
| `NewLoopAgent` | 创建循环 Agent，指定子 Agent 和最大迭代次数 |
| `BreakLoopAction` | 触发退出循环的 Action |
| `SendToolGenAction` | 在工具中发送 Agent Action |
| `ReturnDirectly` | 工具调用后直接返回，不进入下一轮 |

## 2. Human-in-the-Loop（人机协作）

**位置**: `adk/human-in-the-loop/`

### 2.1 审批模式（1_approval）

**场景**: 敏感操作前需要人工确认

```go
// 1_approval/main.go

func main() {
    // 1. 创建带审批工具的 Agent
    agent, _ := adk.NewChatModelAgent(ctx, &adk.ChatModelAgentConfig{
        Name:        "approval_agent",
        Instruction: "你是一个助手...",
        Model:       model,
        ToolsConfig: adk.ToolsConfig{
            ToolsNodeConfig: compose.ToolsNodeConfig{
                Tools: []tool.BaseTool{approvalTool},
            },
            ReturnDirectly: map[string]bool{
                "approval": true,  // 审批工具调用后等待用户
            },
        },
    })

    // 2. 执行
    runner := adk.NewRunner(ctx, adk.RunnerConfig{
        EnableStreaming: true,
        Agent:          agent,
    })

    iter := runner.Query(ctx, "帮我执行删除操作")

    for event := range iter.Iter() {
        if event.Action != nil && event.Action.Interrupted != nil {
            // 中断，等待用户审批
            fmt.Println("需要审批:", event.Action.Interrupted.Reason)

            // 用户确认
            approved := askUserConfirmation()
            if approved {
                iter.Resume(ctx, approvedInput)
            }
        }
    }
}
```

### 2.2 审核编辑模式（2_review-and-edit）

**场景**: 审查并修改工具调用参数

```go
// 审核编辑的核心逻辑
func handleReviewAndEdit(event *adk.AgentEvent) {
    if event.Action != nil && event.Action.Interrupted != nil {
        // 获取待审核的参数
        toolCall := extractToolCall(event)

        // 显示给用户
        fmt.Printf("工具: %s\n", toolCall.Name)
        fmt.Printf("参数: %s\n", toolCall.Arguments)

        // 用户可以选择：批准、拒绝、修改参数
        choice := askUserChoice()

        switch choice {
        case "approve":
            iter.Resume(ctx, &adk.ResumeInput{Approved: true})
        case "reject":
            iter.Resume(ctx, &adk.ResumeInput{Approved: false})
        case "modify":
            newArgs := askUserModify()
            iter.Resume(ctx, &adk.ResumeInput{
                Approved: true,
                ModifiedArgs: newArgs,
            })
        }
    }
}
```

### 2.3 反馈循环模式（3_feedback-loop）

**场景**: Writer + Reviewer 协作，支持人工反馈

```
用户 → Writer → Reviewer → 用户反馈 → Writer → ...
                                    ↓
                                  满意
                                    ↓
                                最终结果
```


| 模式 | 中断类型 | 用户操作 |
|------|---------|---------|

## 3. Graph 编排

**位置**: `compose/graph/`

### 3.1 简单 Graph

```go
// compose/graph/simple/main.go

func main() {
    ctx := context.Background()

    // 1. 创建 Graph
    g := compose.NewGraph[string, string]()

    // 2. 添加 Lambda 节点
    g.AddLambdaNode("uppercase",
        compose.InvokableLambda(func(ctx context.Context, input string) (string, error) {
            return strings.ToUpper(input), nil
        }),
        compose.WithNodeName("uppercase"),
    )

    g.AddLambdaNode("reverse",
        compose.InvokableLambda(func(ctx context.Context, input string) (string, error) {
            runes := []rune(input)
            for i, j := 0, len(runes)-1; i < j; i, j = i+1, j-1 {
                runes[i], runes[j] = runes[j], runes[i]
            }
            return string(runes), nil
        }),
        compose.WithNodeName("reverse"),
    )

    // 3. 添加边
    g.AddEdge(compose.START, "uppercase")
    g.AddEdge("uppercase", "reverse")
    g.AddEdge("reverse", compose.END)

    // 4. 编译执行
    runner, _ := g.Compile(ctx)
    result, _ := runner.Invoke(ctx, "hello")

    fmt.Println(result) // 输出: OLLEH
}
```

```go
// compose/graph/state/main.go

// 定义状态
type CounterState struct {
    Count   int
    History []string
}

// 创建带状态的 Graph
g := compose.NewGraph[string, *CounterState]()

// 添加节点，状态会自动传递
g.AddLambdaNode("increment",
    compose.InvokableLambda(func(ctx context.Context, input string, state *CounterState) (string, *CounterState, error) {

        state.History = append(state.History, fmt.Sprintf("incremented to %d", state.Count))
        return fmt.Sprintf("Count is now %d", state.Count), state, nil

    compose.WithGenLocalState(func() *CounterState {
        return &CounterState{Count: 0, History: []string{}}
    }),
)

```

### 3.3 带工具调用的 Graph

```go
// compose/graph/tool_call_agent/main.go

func main() {
    g := compose.NewGraph[*schema.Message, *schema.Message]()

    // 1. LLM 节点
    llmNode := compose.NewChatModelNode("llm",
        chatModel,
        compose.WithNodeName("llm"),
    )

    // 2. 工具节点
    toolsNode := compose.NewToolsNode("tools",
        &compose.ToolsNodeConfig{
            Tools: []tool.BaseTool{searchTool, calculatorTool},
        },
        compose.WithNodeName("tools"),
    )

    // 3. 添加节点
    g.AddChatModelNode("llm", chatModel)
    g.AddToolsNode("tools", toolsNode)

    // 4. 条件分支：检查是否需要工具
    branch := compose.NewStreamGraphBranch(
        func(ctx context.Context, msg *schema.Message) (string, error) {
            if len(msg.ToolCalls) > 0 {
                return "tools", nil
            }
            return compose.END, nil
        },
        map[string]bool{
            compose.END:  true,
            "tools":      true,
        },
    )
    g.AddBranch("llm", branch)

    // 5. 边连接
    g.AddEdge(compose.START, "llm")
    g.AddEdge("tools", "llm")  // 工具执行后回到 LLM

    // 6. 编译执行
    runner, _ := g.Compile(ctx)
    result, _ := runner.Invoke(ctx, schema.UserMessage("北京天气"))
}
```

## 4. ReAct Agent

**位置**: `flow/agent/react/`

### 4.1 完整示例

```go
// flow/agent/react/react.go

func main() {
    ctx := context.Background()

    // 1. 准备模型
    model, _ := ark.NewChatModel(ctx, &ark.ChatModelConfig{
        Model:  os.Getenv("ARK_MODEL"),
        APIKey: os.Getenv("ARK_API_KEY"),
    })

    // 2. 准备工具
    searchTool, _ := duckduckgo.NewTextSearchTool(ctx, nil)

    // 3. 创建 ReAct Agent
    agent, err := react.NewAgent(ctx, &react.AgentConfig{
        Model: model,
        ToolsConfig: compose.ToolsNodeConfig{
            Tools: []tool.BaseTool{searchTool},
        },
        MaxStep: 10,
    })

    // 4. 执行
    messages := []*schema.Message{
        schema.SystemMessage("你是一个有帮助的助手，可以使用搜索工具。"),
        schema.UserMessage("北京今天的天气怎么样？"),
    }

    stream, _ := agent.Stream(ctx, messages)

    // 5. 处理流
    for {
        chunk, err := stream.Recv()
        if errors.Is(err, io.EOF) {
            break
        }
        if err != nil {
            log.Fatal(err)
        }

        // 打印内容
        if chunk.Content != "" {
            fmt.Print(chunk.Content)
        }

        // 如果是工具调用，显示调用信息
        if len(chunk.ToolCalls) > 0 {
            fmt.Printf("\n[调用工具: %s]\n", chunk.ToolCalls[0].Function.Name)
        }
    }
}
```

### 4.3 带记忆的 ReAct Agent

```go
// flow/agent/react/memory_example/

type AgentWithMemory struct {
    agent   *react.Agent
    memory  *SimpleMemory
}

func (a *AgentWithMemory) Chat(ctx context.Context, query string) (*schema.Message, error) {
    // 1. 获取历史
    history := a.memory.GetMessages()

    // 2. 构建消息
    messages := append(history, schema.UserMessage(query))

    // 3. 执行 Agent
    stream, _ := a.agent.Stream(ctx, messages)

    // 4. 收集响应
    fullMsg := &schema.Message{Role: schema.Assistant}
    for {
        chunk, err := stream.Recv()
        if errors.Is(err, io.EOF) {
            break
        }
        fullMsg.Content += chunk.Content
    }

    // 5. 保存到记忆
    a.memory.Append(schema.UserMessage(query))
    a.memory.Append(fullMsg)

    return fullMsg, nil
}
```

```go
// Agent A 转移到 Agent B
transferAgent, _ := adk.NewChatModelAgent(ctx, &adk.ChatModelAgentConfig{
    Name:        "agent_a",
    Instruction: `你负责接待用户。
如果用户询问代码相关问题，使用 transfer_to_code_agent 转移。
如果用户询问写作相关问题，使用 transfer_to_writer_agent 转移。`,
    Model: model,
    ToolsConfig: adk.ToolsConfig{
        ToolsNodeConfig: compose.ToolsNodeConfig{
            Tools: []tool.BaseTool{transferTool},
        },
    },
})

// 转移工具实现
transferTool, _ := utils.InferTool("transfer_to_agent", "转移任务到其他Agent",
    func(ctx context.Context, req *TransferRequest) (string, error) {
        adk.SendToolGenAction(ctx, "transfer",
            &adk.TransferToAgentAction{
                TargetAgent: req.TargetAgent,
            })
        return "", nil
    })
```

## 总结

| 示例 | 模式 | 适用场景 |
|------|------|---------|
| `loop` | 循环反思 | 质量要求高的创作 |
| `human-in-the-loop/*` | 人机协作 | 需要人工介入的场景 |
| `graph/*` | DAG 编排 | 复杂工作流 |
| `react` | ReAct | 工具调用场景 |
| `supervisor` | 监督者 | 多 Agent 协调 |
