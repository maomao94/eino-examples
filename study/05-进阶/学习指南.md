## 1. 概述

### 1.1 Eino 是什么

Eino 是字节跳动开发的 **Go 语言 AI Agent 开发框架**，用于构建基于大语言模型（LLM）的智能应用。

```
┌─────────────────────────────────────────────────────────────────┐
│                         Eino 在 AI 应用中的位置                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   ┌─────────────┐                                               │
│   │  Your App   │  ← 你的业务代码                               │
│   └──────┬──────┘                                               │
│          │                                                       │
│   ┌──────▼──────┐                                               │
│   │    Eino     │  ← Agent 编排、组件组合、运行时支持            │
│   └──────┬──────┘                                               │
│          │                                                       │
│   ┌──────▼──────┐                                               │
│   │   LLM API   │  ← OpenAI、Claude、Ark 等                     │
│   └─────────────┘                                               │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 为什么要用 Eino

| 问题 | 传统方案 | Eino 方案 |
|------|---------|----------|
| 切换模型 | 重写业务代码 | 换一行配置 |
| 添加工具 | 自己实现调用逻辑 | 实现 Tool 接口 |
| 多轮对话 | 自己管理上下文 | Memory 模块 |
| 流式输出 | 自己处理 SSE | 内置支持 |
| 中断恢复 | 自己保存状态 | Interrupt/Checkpoint |
| 复杂流程 | 逻辑耦合 | Graph 编排 |

### 1.3 Eino 核心特性

- **模块化设计**：Component 接口，支持可替换实现
- **多种 Agent 模式**：ReAct、Plan-Execute、Supervisor 等
- **丰富工具生态**：内置搜索、文件操作、代码执行等
- **流式处理**：完整的流式输出支持
- **可观测性**：日志、追踪、回调机制
- **人机协作**：Interrupt/Resume 支持审批交互

### 1.4 相关仓库

| 仓库 | 说明 |
|------|------|
| **eino** | 核心库，定义接口和编排抽象 |
| **eino-ext** | 扩展库，提供各类 Component 实现（OpenAI、Ark、Milvus 等） |
| **eino-examples** | 示例代码库，本指南的实践素材 |

### 3.1 Component 抽象

Component 是 Eino 的核心设计，每个 Component 接口描述一类可替换的能力。

│           │                    │                    │          │

### 3.2 Runnable 接口

Runnable 是 Eino 的核心抽象，表示可执行对象。

```go
// 四种数据流模式
type Runnable[I, O any] interface {
    // 普通调用: input → output
    Invoke(ctx context.Context, input I, opts ...Option) (output O, err error)

    // 流式调用: input → stream[output]
    Stream(ctx context.Context, input I, opts ...Option) (output *StreamReader[O], err error)

    // 收集调用: stream[input] → output
    Collect(ctx context.Context, input *StreamReader[I], opts ...Option) (output O, err error)

    // 转换调用: stream[input] → stream[output]
    Transform(ctx context.Context, input *StreamReader[I], opts ...Option) (output *StreamReader[O], err error)
}
```

### 3.3 Message 结构

Message 是 Eino 里对话数据的基本单位。

```go
type Message struct {
    Role       RoleType    // system/user/assistant/tool
    Content    string      // 文本内容

    // 多模态支持
    UserInputMultiContent    []MessageInputPart    // 图片等
    AssistantGenMultiContent []MessageOutputPart   // 多模态输出

    // 工具调用
    ToolCalls  []ToolCall  // 当前消息调用的工具
    ToolCallID string      // 工具调用ID
    ToolName   string      // 工具名称

    // 元数据
    ResponseMeta    *ResponseMeta  // Token使用量
    ReasoningContent string       // 推理内容
}

type RoleType string
const (
    System    RoleType = "system"
    User      RoleType = "user"
    Assistant RoleType = "assistant"
    Tool      RoleType = "tool"
)
```

## 4. 核心组件

### 4.1 ChatModel

ChatModel 是与大语言模型通信的接口。

```go
// 基础接口
type BaseChatModel interface {
    Generate(ctx context.Context, input []*Message,
             opts ...Option) (*Message, error)
    Stream(ctx context.Context, input []*Message,
           opts ...Option) (*StreamReader[*Message], error)
}

// 带工具绑定的安全版本（推荐）
type ToolCallingChatModel interface {
    BaseChatModel
    WithTools(tools []*ToolInfo) (ToolCallingChatModel, error)
}
```

**使用示例**:

```go
// 1. 创建模型
model, err := ark.NewChatModel(ctx, &ark.ChatModelConfig{
    Model:  "ep-xxxx",
    APIKey: "xxx",
})

// 2. 同步调用
msg, err := model.Generate(ctx, []*schema.Message{
    schema.SystemMessage("你是一个有帮助的助手"),
    schema.UserMessage("你好"),
})

// 3. 流式调用
stream, err := model.Stream(ctx, messages)
for {
    chunk, err := stream.Recv()
    if err == io.EOF { break }
    fmt.Print(chunk.Content)
}
```

### 4.2 Tool

Tool 让 Agent 能够执行实际操作。

```go
// 同步执行工具
type InvokableTool interface {
    BaseTool
    InvokableRun(ctx context.Context, argumentsInJSON string,
                 opts ...Option) (string, error)
}

// 工具元数据
type BaseTool interface {
    Info(ctx context.Context) (*ToolInfo, error)
}

type ToolInfo struct {
    Name        string      // 工具名称
    Desc        string      // 工具描述
    ArgsSchema  interface{} // 参数Schema
}
```

**创建工具的两种方式**:

```go
// 方式1: 使用 InferTool（推荐）
tool, err := utils.InferTool("calculator", "执行数学计算",
    func(ctx context.Context, req *CalcRequest) (string, error) {
        result := req.A + req.B
        return fmt.Sprintf("%d", result), nil
    })

type CalcRequest struct {
    A int `json:"a"`
    B int `json:"b"`
}

// 方式2: 实现完整接口
type MyTool struct{}
func (t *MyTool) Info(ctx context.Context) (*ToolInfo, error) {...}
func (t *MyTool) InvokableRun(ctx context.Context, args string, opts ...Option) (string, error) {...}
```

### 4.3 Agent

Agent 是能够自主决策使用工具的智能体。

```go
// Agent 接口
type Agent interface {
    Name(ctx context.Context) string
    Description(ctx context.Context) string
    Run(ctx context.Context, input *AgentInput,
        options ...AgentRunOption) *AsyncIterator[*AgentEvent]
}

// Agent 输入
type AgentInput struct {
    Query        string
    Conversation []*Message  // 对话历史
    State        map[string]any  // 自定义状态
}

// Agent 事件
type AgentEvent struct {
    AgentName string
    RunPath   []RunStep
    Output    *AgentOutput
    Action    *AgentAction  // 特殊动作
    Err       error
}
```

**ReAct Agent 示例**:

```go
agent, err := react.NewAgent(ctx, &react.AgentConfig{
    Model: model,
    ToolsConfig: compose.ToolsNodeConfig{
        Tools: []tool.BaseTool{searchTool, calculatorTool},
    },
    MaxStep: 10,  // 最大迭代次数
})

// 执行
events := agent.Run(ctx, &AgentInput{Query: "北京天气"})

for event := range events.Iter() {
    if event.Output != nil {
        fmt.Println(event.Output.Message.Content)
    }
}
```

### 4.5 Memory

Memory 管理对话历史和上下文。

```go
// 简单内存实现
type SimpleMemory struct {
    mu           sync.RWMutex
    conversations map[string]*Conversation
    maxWindow    int  // 最大保留消息数
}

func (m *SimpleMemory) GetMessages(conversationID string) []*schema.Message {
    msgs := m.getConversation(conversationID).GetMessages()
    // 只返回最近的消息
    if len(msgs) > m.maxWindow {
        return msgs[len(msgs)-m.maxWindow:]
    }
    return msgs
}

func (m *SimpleMemory) Append(conversationID string, msg *schema.Message) {
    m.mu.Lock()
    defer m.mu.Unlock()
    conv := m.getOrCreate(conversationID)
    conv.Append(msg)
}
```

## 5. 进阶主题

### 5.1 Chain 编排

Chain 是最简单的编排方式，将组件线性串联。

```
Input ──► ChatTemplate ──► ChatModel ──► Output
```

```go
// 创建 Chain
chain := compose.NewChain[*schema.Message, *schema.Message]()

chain.
    AppendChatTemplate(promptTemplate).
    AppendChatModel(chatModel)

runner, err := chain.Compile(ctx)
result, err := runner.Invoke(ctx, messages)
```

### 5.2 Graph 编排

Graph 支持复杂的 DAG（有向无环图）编排。

```
                    ┌──────────────┐
                    │   Input     │
                    └──────┬──────┘
                           │
            ┌──────────────┼──────────────┐
            ▼              ▼              ▼
      ┌──────────┐  ┌───────────┐  ┌──────────┐
      │ Branch A │  │ Branch B  │  │ Branch C │
      └────┬─────┘  └─────┬─────┘  └────┬─────┘
           └──────────────┼──────────────┘
                          ▼
                    ┌──────────────┐
                    │    Merge     │
                    └──────┬──────┘
                           ▼
                      ┌────────┐
                      │ Output │
                      └────────┘
```

```go
g := compose.NewGraph[*Input, *Output]()

// 添加节点
g.AddChatModelNode("llm", model)
g.AddToolsNode("tools", toolsNode)
g.AddLambdaNode("processor", processor)

// 添加条件分支
branch := compose.NewStreamGraphBranch(checkFunc, nextNodes)
g.AddBranch("llm", branch)

// 连接边
g.AddEdge(compose.START, "llm")
g.AddEdge("tools", "llm")
g.AddEdge("llm", compose.END)

runner, err := g.Compile(ctx)
```

### 5.3 Middleware

Middleware 提供横切关注点的扩展能力。

```go
// Agent 中间件
type ChatModelAgentMiddleware interface {
    BeforeAgent(ctx context.Context, runCtx *ChatModelAgentContext) (context.Context, *ChatModelAgentContext, error)
    AfterModelRewriteState(ctx context.Context, state *ChatModelAgentState, mc *ModelContext) (context.Context, *ChatModelAgentState, error)
    WrapModel(ctx context.Context, m model.BaseChatModel, mc *ModelContext) (model.BaseChatModel, error)
}

// Tool 中间件
type InvokableToolMiddleware interface {
    BeforeInvoke(ctx context.Context, input []any) (context.Context, []any, error)
    AfterInvoke(ctx context.Context, output string) (context.Context, string, error)
}
```

### 5.4 Callback

Callback 提供可观测性支持。

```go
// Callback 定义
type Handler interface {
    OnStart(ctx context.Context, input any) context.Context
    OnEnd(ctx context.Context, input, output any)
    OnError(ctx context.Context, err error)
    OnStartPart(ctx context.Context, input any) context.Context
    OnEndPart(ctx context.Context, output any)
}

// 使用示例
runner, err := compose.NewChain(...)
runner, err = compose.WithCallbacks(runner, &callbacks.Handler{
    OnStart: func(ctx context.Context, input any) context.Context {
        log.Printf("Started: %+v", input)
        return ctx
    },
    OnEnd: func(ctx context.Context, input, output any) {
        log.Printf("Ended with output: %+v", output)
    },
})
```

### 5.5 Interrupt 与 Resume

Interrupt 支持长时间任务的人机协作。

```go
// 中断 Agent 执行
type InterruptInfo struct {
    Reason   string
    Checkpoint []byte  // 恢复点
}

// 创建带中断的 Agent
agent, err := react.NewAgent(ctx, &react.AgentConfig{
    Model: model,
    ToolsConfig: compose.ToolsNodeConfig{
        Tools: []tool.BaseTool{bookingTool},
    },
})

// 执行时检测中断
events := agent.Run(ctx, input)
for event := range events.Iter() {
    if event.Action != nil && event.Action.Interrupted != nil {
        // 用户确认或修改
        approved := userConfirm(event.Action.Interrupted)
        if approved {
            events.Resume(ctx, approvedInput)
        }
    }
}
```

### 5.6 Multi-Agent

ADK 提供多 Agent 协作模式。

```go
// LoopAgent - 循环反思
la, err := adk.NewLoopAgent(ctx, &adk.LoopAgentConfig{
    SubAgents: []adk.Agent{
        mainAgent,      // 执行任务
        critiqueAgent,  // 审查结果
    },
    MaxIterations: 5,
})

// SequentialAgent - 顺序执行
sa, err := adk.NewSequentialAgent(ctx, &adk.SequentialAgentConfig{
    SubAgents: []adk.Agent{agent1, agent2, agent3},

// ParallelAgent - 并行执行

    SubAgents: []adk.Agent{agent1, agent2, agent3},
})

// Supervisor - 监督者模式
supervisor, err := prebuilt/supervisor.New(ctx, &prebuilt/supervisor.Config{
    Model: model,
    SubAgents: []adk.Agent{agentA, agentB, agentC},
})
```
