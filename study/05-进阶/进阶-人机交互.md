## 1. 概述

### 1.1 什么是 Human-in-the-Loop

Human-in-the-Loop (HITL) 是一种将人类智能融入 AI 自动化流程的设计模式：

```
┌─────────────────────────────────────────────────────────────────┐
│                 Human-in-the-Loop 流程                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐                   │
│  │   AI     │───▶│  中断点   │───▶│  人类    │                   │
│  │  执行    │    │          │    │  决策    │                   │
│  └──────────┘    └──────────┘    └────┬─────┘                   │
│                                       │                          │
│                                       ▼                          │
│                              ┌─────────────────┐                │
│                              │   批准/修改/拒绝  │                │
│                              └────────┬────────┘                │
│                                       │                          │
│          ┌───────────────────────────┼───────────────────┐     │
│          │                           │                   │     │
│          ▼                           ▼                   ▼     │
│    ┌──────────┐              ┌──────────┐          ┌──────────┐ │
│    │ 继续执行 │              │ 替代执行 │          │  终止    │ │
│    └──────────┘              └──────────┘          └──────────┘ │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 应用场景

| 场景 | 说明 | 价值 |
|------|------|------|
| 审批流程 | 金融交易、合同签署 | 降低风险 |
| 内容审核 | 敏感内容过滤 | 合规保障 |
| 异常处理 | 未知情况处理 | 提高鲁棒性 |
| 知识验证 | 事实核查 | 准确性 |
| 参数调整 | 干预 AI 决策 | 可控性 |

## 2. 中断机制

### 2.1 Interrupt 原理

Interrupt 是 Eino 中实现人机交互的核心机制：

```go
// Interrupt 定义
// 位于：github.com/cloudwego/eino/adk/interrupt

type Interrupt struct {
    ID          string            // 中断唯一 ID
    Type        InterruptType     // 中断类型
    Message     string            // 中断消息
    State       map[string]any    // 当前状态
    CreatedAt   time.Time         // 创建时间
    ResolvedAt  *time.Time        // 解决时间
}

// 中断类型
type InterruptType string

const (
    InterruptTypeApproval   InterruptType = "approval"   // 审批类型
    InterruptTypeConfirm    InterruptType = "confirm"    // 确认类型
    InterruptTypeCheckpoint  InterruptType = "checkpoint" // 检查点类型
)
```

### 2.2 中断工作流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     中断执行流程                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  1. Agent 执行到中断点                                            │
│     │                                                             │
│     ▼                                                             │
│  2. 保存当前状态到 CheckpointStore                               │
│     │                                                             │
│     ▼                                                             │
│  3. 返回 Interrupt 给调用者                                      │
│     │                                                             │
│     ▼                                                             │
│  4. 人类处理中断（审批/修改/拒绝）                                │
│     │                                                             │
│     ▼                                                             │
│  5. 根据处理结果恢复执行                                          │
│     │                                                             │
│     ├── ResumeWithResult: 使用新结果继续执行                      │
│     ├── ResumeWithParams: 修改参数后继续执行                      │
│     └── Abort: 终止执行                                          │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 2.3 基本中断示例

**功能说明**：在 Agent 执行过程中插入中断点

**关键组件**：
- `interrupt.NewInterrupt`: 创建中断
- `runner.ResumeWithParams`: 恢复执行
- `runner.Abort`: 终止执行

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/cloudwego/eino/adk/agent"
	"github.com/cloudwego/eino/adk/interrupt"
	"github.com/cloudwego/eino/adk/runner"
	"github.com/cloudwego/eino/chatbot/openai"
)

// 使用中断实现审批流程

func main() {
	ctx := context.Background()

	// 1. 创建 Agent
	model, _ := openai.NewChatModel(ctx, &openai.ChatModelConfig{
		APIKey: "your-api-key",
		Model:  "gpt-4o-mini",
	})

	// 创建带审批的工具
	approvalTool := &ApprovalRequiredTool{
		Name:        "execute_payment",
		Description: "执行支付，需要审批",
	}

	agent, _ := agent.NewAgent(ctx, &agent.AgentConfig{
		Model: model,
		Tools: []agent.Tool{approvalTool},
	})

	// 2. 创建 Runner
	run := runner.NewAgentRunner(ctx, agent)

	// 3. 运行，预期会触发中断
	fmt.Println("开始执行支付请求...")
	result, err := run.Run(ctx, "执行一笔 10000 元的转账")

	if err != nil {
		// 检查是否是中断错误
		if isInterrupt(err) {
			handleInterrupt(ctx, err)
		} else {
			log.Fatalf("执行失败: %v", err)
		}
	}

	fmt.Println("执行结果:", result)
}

// 处理中断
func handleInterrupt(ctx context.Context, err error) {
	intr := extractInterrupt(err)

	fmt.Printf("=== 需要人工处理 ===\n")
	fmt.Printf("中断类型: %s\n", intr.Type)
	fmt.Printf("消息: %s\n", intr.Message)
	fmt.Printf("状态: %v\n", intr.State)

	// 模拟人工审批
	var approved bool
	var modifiedAmount float64 = 10000

	fmt.Print("是否批准? (yes/no): ")
	fmt.Scanf("%s", &approved)

	if approved {
		fmt.Println("审批通过，修改金额为:", modifiedAmount)
		// 恢复执行
		run := runner.NewAgentRunner(ctx, nil)
		result, err := run.ResumeWithParams(ctx, intr.ID, map[string]any{
			"approved": true,
			"amount":   modifiedAmount,
		})
		if err != nil {
			log.Fatalf("恢复执行失败: %v", err)
		}
		fmt.Println("最终结果:", result)
	} else {
		fmt.Println("审批拒绝")
		// 终止执行
		runner.Abort(ctx, intr.ID)
	}
}

// ApprovalRequiredTool 需要审批的工具
type ApprovalRequiredTool struct {
	Name        string
	Description string
}

func (t *ApprovalRequiredTool) Info() *agent.ToolInfo {
	return &agent.ToolInfo{
		Name:        t.Name,
		Description: t.Description,
		Parameters: map[string]interface{}{
			"type": "object",
			"properties": map[string]interface{}{
				"amount": map[string]interface{}{
					"type":        "number",
					"description": "支付金额",
				},
				"to": map[string]interface{}{
					"type":        "string",
					"description": "收款人",
				},
			},
			"required": []string{"amount"},
		},
	}
}

func (t *ApprovalRequiredTool) Invoke(ctx context.Context, params map[string]any) (string, error) {
	// 触发中断等待审批
	intr := interrupt.NewInterrupt(
		interrupt.InterruptTypeApproval,
		"支付审批",
		map[string]any{
			"action":    "execute_payment",
			"amount":    params["amount"],
			"recipient": params["to"],
		},
	)

	// 返回中断错误，触发调用者处理
	return "", intr
}

// 辅助函数
func isInterrupt(err error) bool {
	_, ok := err.(*interrupt.Interrupt)
	return ok
}

func extractInterrupt(err error) *interrupt.Interrupt {
	if intr, ok := err.(*interrupt.Interrupt); ok {
		return intr
	}
	return nil
}
```

## 3. 批准包装器

### 3.1 Approval Wrapper 原理

Approval Wrapper 是将普通工具包装成需要审批的审批工具的机制：

```
┌─────────────────────────────────────────────────────────────────┐
│                   Approval Wrapper 原理                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ┌──────────────────┐                                           │
│  │ InvokableTool    │  原工具                                    │
│  │ (普通工具)        │                                           │
│  └────────┬─────────┘                                           │
│           │                                                      │
│           ▼                                                      │
│  ┌──────────────────┐                                           │
│  │ ApprovableTool   │  包装后的审批工具                           │
│  │ (包装器)         │                                           │
│  └────────┬─────────┘                                           │
│           │                                                      │
│           ▼                                                      │
│  ┌──────────────────┐                                           │
│  │ ApprovalHandler  │  审批处理器                                │
│  └──────────────────┘                                           │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 InvokableApprovableTool 使用

```go
package main

import (
	"context"
	"fmt"

	"github.com/cloudwego/eino/adk/agent"
	"github.com/cloudwego/eino/adk/approval"
)

// ApprovableTool 包装器使用示例

func main() {
	// 1. 定义原工具
	baseTool := &BaseTool{
		Name: "send_email",
	}

	// 2. 创建审批处理器
	approvalHandler := approval.NewHandler(
		approval.WithApprover(func(ctx context.Context, req *approval.Request) (*approval.Response, error) {
			fmt.Printf("需要审批: %s\n", req.Message)
			fmt.Printf("参数: %v\n", req.Params)

			// 这里可以集成审批系统
			// 例如：发送邮件通知、创建工单等

			// 返回审批结果
			return &approval.Response{
				Approved: true,
				Note:    "管理员审批通过",
				ModifiedParams: nil, // 不修改参数
			}, nil
		}),
	)

	// 3. 包装工具
	approvableTool := approval.NewApprovableTool(
		baseTool,
		approvalHandler,
	)

	// 4. 使用包装后的工具
	ctx := context.Background()
	result, err := approvableTool.Invoke(ctx, map[string]any{
		"to":      "user@example.com",
		"subject": "测试邮件",
		"body":    "这是一封测试邮件",
	})

	if err != nil {
		if approval.IsApprovalRequired(err) {
			// 处理需要审批的情况
			fmt.Println("需要人工审批")
		}
	}

	fmt.Println("执行结果:", result)
}

// BaseTool 基础工具
type BaseTool struct {
	Name string
}

func (t *BaseTool) Info() *agent.ToolInfo {
	return &agent.ToolInfo{
		Name:        t.Name,
		Description: "发送邮件",
		Parameters: map[string]interface{}{
			"type": "object",
			"properties": map[string]interface{}{
				"to":      map[string]interface{}{"type": "string"},
				"subject": map[string]interface{}{"type": "string"},
				"body":    map[string]interface{}{"type": "string"},
			},
			"required": []string{"to", "subject", "body"},
		},
	}
}

func (t *BaseTool) Invoke(ctx context.Context, params map[string]any) (string, error) {
	to := params["to"].(string)
	subject := params["subject"].(string)
	body := params["body"].(string)

	return fmt.Sprintf("邮件已发送给 %s, 主题: %s, 内容: %s", to, subject, body), nil
}
```

### 3.3 自定义审批逻辑

```go
package main

import (
	"context"
	"fmt"
	"time"

	"github.com/cloudwego/eino/adk/approval"
)

// 条件审批处理器示例

type ConditionalApprovalHandler struct {
	// 审批阈值
	AmountThreshold float64
	Approvers       map[string]string // role -> approver
}

func NewConditionalApprovalHandler() *ConditionalApprovalHandler {
	return &ConditionalApprovalHandler{
		AmountThreshold: 10000,
		Approvers: map[string]string{
			"admin":   "admin@company.com",
			"finance": "finance@company.com",
		},
	}
}

func (h *ConditionalApprovalHandler) Approve(ctx context.Context, req *approval.Request) (*approval.Response, error) {
	amount, ok := req.Params["amount"].(float64)
	if !ok {
		return &approval.Response{
			Approved: false,
			Note:     "无法解析金额",
		}, nil
	}

	// 根据金额决定审批级别
	var approver string
	if amount > 100000 {
		approver = h.Approvers["admin"]
	} else if amount > h.AmountThreshold {
		approver = h.Approvers["finance"]
	} else {
		// 小额免审批
		return &approval.Response{
			Approved: true,
			Note:     "小额交易自动审批",
		}, nil
	}

	// 发送审批请求
	fmt.Printf("发送审批请求到: %s\n", approver)
	fmt.Printf("金额: %.2f\n", amount)
	fmt.Printf("描述: %s\n", req.Message)

	// 模拟等待审批
	fmt.Println("等待审批中...")
	time.Sleep(2 * time.Second)

	// 模拟审批通过
	return &approval.Response{
		Approved:       true,
		Note:           fmt.Sprintf("由 %s 审批通过", approver),
		ModifiedParams: nil,
	}, nil
}
```

## 4. 检查点

### 4.1 Checkpoint 原理

Checkpoint 用于保存 Agent 执行过程中的状态，支持中断后的恢复：

```go
// CheckPointStore 接口
// 位于：github.com/cloudwego/eino/adk/checkpoint

type CheckPointStore interface {
    // Save 保存检查点
    Save(ctx context.Context, checkpoint *Checkpoint) error

    // Load 加载检查点
    Load(ctx context.Context, id string) (*Checkpoint, error)

    // Delete 删除检查点
    Delete(ctx context.Context, id string) error

    // List 列出所有检查点
    List(ctx context.Context) ([]*Checkpoint, error)
}

// Checkpoint 定义
type Checkpoint struct {
    ID        string
    AgentID   string
    State     map[string]any     // Agent 状态
    History   []*Turn             // 对话历史
    Timestamp time.Time
    Metadata  map[string]any     // 额外元数据
}
```

### 4.2 内存存储实现

```go
package main

import (
	"context"
	"fmt"
	"sync"
	"time"

	"github.com/cloudwego/eino/adk/checkpoint"
)

// MemoryCheckpointStore 内存检查点存储
// 适用于单机部署和开发测试

type MemoryCheckpointStore struct {
	mu         sync.RWMutex
	checkpoints map[string]*checkpoint.Checkpoint
}

func NewMemoryCheckpointStore() *MemoryCheckpointStore {
	return &MemoryCheckpointStore{
		checkpoints: make(map[string]*checkpoint.Checkpoint),
	}
}

func (s *MemoryCheckpointStore) Save(ctx context.Context, cp *checkpoint.Checkpoint) error {
	s.mu.Lock()
	defer s.mu.Unlock()

	cp.Timestamp = time.Now()
	s.checkpoints[cp.ID] = cp
	fmt.Printf("检查点已保存: %s\n", cp.ID)
	return nil
}

func (s *MemoryCheckpointStore) Load(ctx context.Context, id string) (*checkpoint.Checkpoint, error) {
	s.mu.RLock()
	defer s.mu.RUnlock()

	cp, exists := s.checkpoints[id]
	if !exists {
		return nil, fmt.Errorf("检查点不存在: %s", id)
	}
	return cp, nil
}

func (s *MemoryCheckpointStore) Delete(ctx context.Context, id string) error {
	s.mu.Lock()
	defer s.mu.Unlock()

	delete(s.checkpoints, id)
	return nil
}

func (s *MemoryCheckpointStore) List(ctx context.Context) ([]*checkpoint.Checkpoint, error) {
	s.mu.RLock()
	defer s.mu.RUnlock()

	result := make([]*checkpoint.Checkpoint, 0, len(s.checkpoints))
	for _, cp := range s.checkpoints {
		result = append(result, cp)
	}
	return result, nil
}

// 使用示例
func main() {
	ctx := context.Background()
	store := NewMemoryCheckpointStore()

	// 保存检查点
	cp := &checkpoint.Checkpoint{
		ID:      "session-123",
		AgentID: "agent-456",
		State: map[string]any{
			"step":       3,
			"last_action": "retrieved_data",
		},
		History: []*checkpoint.Turn{
			{User: "查询余额", Assistant: "正在查询..."},
		},
	}
	store.Save(ctx, cp)

	// 加载检查点
	loaded, _ := store.Load(ctx, "session-123")
	fmt.Printf("恢复状态: %v\n", loaded.State)
}
```

### 4.3 Redis 存储实现

```go
package main

import (
	"context"
	"encoding/json"
	"fmt"
	"time"

	"github.com/cloudwego/eino/adk/checkpoint"
	"github.com/redis/go-redis/v9"
)

// RedisCheckpointStore Redis 检查点存储
// 适用于分布式部署

type RedisCheckpointStore struct {
	client *redis.Client
	prefix string
}

func NewRedisCheckpointStore(client *redis.Client) *RedisCheckpointStore {
	return &RedisCheckpointStore{
		client: client,
		prefix: "checkpoint:",
	}
}

func (s *RedisCheckpointStore) Save(ctx context.Context, cp *checkpoint.Checkpoint) error {
	data, err := json.Marshal(cp)
	if err != nil {
		return err
	}

	key := s.prefix + cp.ID
	return s.client.Set(ctx, key, data, 24*time.Hour).Err() // 24小时过期
}

func (s *RedisCheckpointStore) Load(ctx context.Context, id string) (*checkpoint.Checkpoint, error) {
	key := s.prefix + id
	data, err := s.client.Get(ctx, key).Bytes()
	if err != nil {
		if err == redis.Nil {
			return nil, fmt.Errorf("检查点不存在: %s", id)
		}
		return nil, err
	}

	var cp checkpoint.Checkpoint
	if err := json.Unmarshal(data, &cp); err != nil {
		return nil, err
	}
	return &cp, nil
}

func (s *RedisCheckpointStore) Delete(ctx context.Context, id string) error {
	key := s.prefix + id
	return s.client.Del(ctx, key).Err()
}

func (s *RedisCheckpointStore) List(ctx context.Context) ([]*checkpoint.Checkpoint, error) {
	keys, err := s.client.Keys(ctx, s.prefix+"*").Result()
	if err != nil {
		return nil, err
	}

	result := make([]*checkpoint.Checkpoint, 0, len(keys))
	for _, key := range keys {
		data, err := s.client.Get(ctx, key).Bytes()
		if err != nil {
			continue
		}

		var cp checkpoint.Checkpoint
		if err := json.Unmarshal(data, &cp); err != nil {
			continue
		}
		result = append(result, &cp)
	}
	return result, nil
}
```

### 4.4 断点恢复流程

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/cloudwego/eino/adk/checkpoint"
	"github.com/cloudwego/eino/adk/runner"
)

// 断点恢复使用示例

func main() {
	ctx := context.Background()

	// 1. 初始化检查点存储
	store := NewMemoryCheckpointStore()

	// 2. 创建带检查点的 Runner
	run := runner.NewAgentRunner(ctx, agent,
		runner.WithCheckpointStore(store), // 启用检查点
	)

	// 3. 首次执行（可能因中断停止）
	sessionID := "session-001"
	result, err := run.Run(ctx, "执行复杂任务")

	if err != nil {
		if isInterrupt(err) {
			fmt.Println("执行中断，检查点已保存")
			// 可以退出程序，稍后恢复
		}
	}

	// 4. 恢复执行
	fmt.Println("恢复执行...")
	restoreCtx := context.WithValue(ctx, checkpoint.ContextKeySessionID, sessionID)
	restoreCtx = checkpoint.WithCheckpointStore(restoreCtx, store)

	restored := runner.NewAgentRunner(ctx, agent,
		runner.WithCheckpointStore(store),
		runner.WithResumeID(sessionID),
	)

	result, err = restored.Run(restoreCtx, "") // 空输入表示继续
	if err != nil {
		log.Fatal(err)
	}

	fmt.Println("恢复后结果:", result)
}
```

## 5. 嵌套中断处理

### 5.1 嵌套场景分析

复杂场景中可能出现嵌套中断：

```
Agent 执行
    │
    ├── 中断点 A（审批）
    │       │
    │       ├── 子 Agent 执行
    │       │       │
    │       │       └── 中断点 B（确认）
    │       │
    │       └── 等待 A 审批
    │
    └── 继续主流程
```

### 5.2 嵌套中断处理策略

```go
package main

import (
	"context"
	"fmt"
	"sync"

	"github.com/cloudwego/eino/adk/interrupt"
)

// NestedInterruptHandler 嵌套中断处理器

type NestedInterruptHandler struct {
	mu       sync.Mutex
	stack    []*interrupt.Interrupt  // 中断栈
	resolved map[string]bool         // 已解决的中断
}

func NewNestedInterruptHandler() *NestedInterruptHandler {
	return &NestedInterruptHandler{
		resolved: make(map[string]bool),
	}
}

func (h *NestedInterruptHandler) Handle(interr *interrupt.Interrupt) error {
	h.mu.Lock()
	defer h.mu.Unlock()

	// 入栈
	h.stack = append(h.stack, interr)
	fmt.Printf("中断入栈 [%s]: %s\n", interr.ID, interr.Message)

	return nil
}

func (h *NestedInterruptHandler) Resolve(id string, approved bool, params map[string]any) error {
	h.mu.Lock()
	defer h.mu.Unlock()

	// 标记为已解决
	h.resolved[id] = approved

	// 出栈（从栈顶开始找）
	for i := len(h.stack) - 1; i >= 0; i-- {
		if h.stack[i].ID == id {
			h.stack = h.stack[:i]
			fmt.Printf("中断出栈 [%s]: approved=%v\n", id, approved)
			break
		}
	}

	// 检查是否还有待处理的中断
	if len(h.stack) > 0 {
		current := h.stack[len(h.stack)-1]
		return h.promptForApproval(current)
	}

	return nil
}

func (h *NestedInterruptHandler) promptForApproval(interr *interrupt.Interrupt) error {
	fmt.Printf("\n=== 待处理中断 ===\n")
	fmt.Printf("ID: %s\n", interr.ID)
	fmt.Printf("类型: %s\n", interr.Type)
	fmt.Printf("消息: %s\n", interr.Message)
	fmt.Printf("状态: %v\n", interr.State)
	return nil
}

func (h *NestedInterruptHandler) HasPending() bool {
	h.mu.Lock()
	defer h.mu.Unlock()
	return len(h.stack) > 0
}

// 使用示例
func main() {
	ctx := context.Background()
	handler := NewNestedInterruptHandler()

	// 模拟嵌套中断
	intrA := interrupt.NewInterrupt(
		interrupt.InterruptTypeApproval,
		"外层审批: 执行转账",
		map[string]any{"action": "transfer"},
	)

	intrB := interrupt.NewInterrupt(
		interrupt.InterruptTypeConfirm,
		"内层确认: 收款人信息",
		map[string]any{"recipient": "user@example.com"},
	)

	// 模拟处理
	handler.Handle(intrA)
	handler.Handle(intrB)

	fmt.Printf("待处理中断数: %d\n", len(handler.stack))

	// 解决内层中断
	handler.Resolve(intrB.ID, true, nil)

	// 解决外层中断
	handler.Resolve(intrA.ID, true, nil)

	fmt.Printf("所有中断已解决，剩余: %d\n", len(handler.stack))
}
```

```go
	h.pending = h.pending[1:]

	return nil

	h.pending = h.pending[1:]
	tx.Description = reason
	h.rejected = append(h.rejected, tx)
```

```go
package main

import (
	"context"
	"fmt"
	"time"

	"github.com/cloudwego/eino/adk/agent"
	"github.com/cloudwego/eino/adk/interrupt"
	"github.com/cloudwego/eino/adk/runner"

// 代码部署审核系统

type DeploymentApprovalSystem struct {
	pendingDeployments []*DeploymentRequest
	approvedDeployments []*DeploymentRequest
}

type DeploymentRequest struct {
	ID          string
	Service     string
	Version     string
	Environment string // dev/staging/production
	Changes     []string
	Risk        string
	ApprovedBy  string
	Timestamp   time.Time
}

func (s *DeploymentApprovalSystem) RequestApproval(req *DeploymentRequest) error {
	// 生产环境部署需要审批
	if req.Environment == "production" {
		// 触发中断
		return &interrupt.Interrupt{
			ID:      fmt.Sprintf("deploy-%s", req.ID),
			Type:    interrupt.InterruptTypeApproval,
			Message: fmt.Sprintf("生产环境部署审批: %s@%s", req.Service, req.Version),
			State: map[string]any{
				"service":    req.Service,
				"version":    req.Version,
				"changes":    req.Changes,
				"environment": req.Environment,
			},
		}
	}

	// 非生产环境自动通过
	s.approvedDeployments = append(s.approvedDeployments, req)
	return nil
}

func (s *DeploymentApprovalSystem) HandleApproval(id string, approved bool, note string) error {
	// 找到对应的部署请求并处理
	for i, req := range s.pendingDeployments {
		if fmt.Sprintf("deploy-%s", req.ID) == id {
			if approved {
				req.ApprovedBy = note
				s.approvedDeployments = append(s.approvedDeployments, req)
			}
			s.pendingDeployments = append(s.pendingDeployments[:i], s.pendingDeployments[i+1:]...)
			return nil
		}
	}
	return fmt.Errorf("部署请求不存在: %s", id)
}
```

### 7.1 中断点设计原则

| 原则 | 说明 | 示例 |
|------|------|------|
| 最小化 | 只在必要时设置中断 | 高风险操作才需要审批 |

| 快速响应 | 避免长时间等待 | 设置超时机制 |
| 可追溯 | 记录所有审批决策 | 保留审计日志 |

```go
type CheckpointPolicy struct {

	BeforeToolCall bool

	AfterTurn bool
```

### 7.3 超时处理

```go
package main

import (
	"context"
	"fmt"
	"time"

	"github.com/cloudwego/eino/adk/interrupt"
)

// 超时处理策略

type TimeoutPolicy struct {
	DefaultTimeout time.Duration
	MaxRetries     int
	Backoff        time.Duration
}

func NewTimeoutPolicy() *TimeoutPolicy {
	return &TimeoutPolicy{
		DefaultTimeout: 30 * time.Minute, // 默认审批超时 30 分钟
		MaxRetries:     3,
		Backoff:        5 * time.Minute,
	}
}

func (p *TimeoutPolicy) HandleTimeout(ctx context.Context, intr *interrupt.Interrupt) error {
	// 检查是否超过最大重试次数
	if retries, ok := intr.State["retry_count"].(int); ok && retries >= p.MaxRetries {
		return fmt.Errorf("审批超时，已达到最大重试次数")
	}

	// 更新重试计数
	intr.State["retry_count"] = retries + 1
	intr.State["last_reminder"] = time.Now()

	// 发送提醒
	fmt.Printf("审批超时提醒 [%s]: 请尽快处理\n", intr.ID)

	return nil
}
```

## 8. 常见问题

### Q1: 中断后无法恢复

**可能原因**：
- CheckpointStore 配置错误
- Session ID 不匹配
- 状态数据损坏

**排查方法**：
1. 检查 CheckpointStore 是否正常工作
2. 确认 Resume ID 与中断 ID 一致
3. 查看保存的 checkpoint 数据

**解决方案**：
```go
// 确保正确配置 CheckpointStore
run := runner.NewAgentRunner(ctx, agent,
	runner.WithCheckpointStore(store),
)

// 使用正确的中断 ID 恢复
restored := runner.NewAgentRunner(ctx, agent,
	runner.WithResumeID(interrupt.ID),
)
```

### Q2: 审批流程卡住

**可能原因**：
- 审批请求未发送成功
- 审批系统响应超时
- 死锁（等待多个审批）

**解决方案**：
1. 添加超时机制
2. 实现重试逻辑
3. 避免循环等待

### Q3: 如何处理并发审批？

**解决方案**：
```go
// 使用带锁的处理器
type ConcurrentApprovalHandler struct {
	mu       sync.Mutex
	pending  map[string]*ApprovalRequest
	handlers map[string]chan *ApprovalResponse
}

func (h *ConcurrentApprovalHandler) RequestApproval(req *ApprovalRequest) <-chan *ApprovalResponse {
	h.mu.Lock()
	defer h.mu.Unlock()

	ch := make(chan *ApprovalResponse, 1)
	h.pending[req.ID] = req
	h.handlers[req.ID] = ch

	// 发送异步通知
	go h.notifyApprover(req)

	return ch
}
```
