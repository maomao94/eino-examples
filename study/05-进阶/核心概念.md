## 1. 为什么需要 Component 接口

### 1.1 问题背景

传统 AI 应用开发中，代码往往与特定模型强耦合：

```go
// 传统方式：直接调用 OpenAI
client := openai.NewClient(apiKey)
response := client.Chat("gpt-4", messages)

// 想换模型？重写！
client := claude.NewClient(apiKey)
response := client.Chat("claude-3", messages)
```

### 1.2 Component 解决方案

Eino 定义统一接口，实现可替换：

```
┌─────────────────────────────────────────────────────────────────┐
│                        Component 接口设计                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│                      ┌─────────────────┐                        │
│                      │ BaseChatModel   │                        │
│                      └────────┬────────┘                        │
│                               │                                   │
│          ┌────────────────────┼────────────────────┐            │
│          │                    │                    │            │
│          ▼                    ▼                    ▼            │
│   ┌─────────────┐     ┌─────────────┐     ┌─────────────┐      │
│   │   OpenAI    │     │    Ark      │     │  Claude     │      │
│   │  (实现)     │     │  (实现)     │     │  (实现)     │      │
│   └─────────────┘     └─────────────┘     └─────────────┘      │
│                                                                  │
│   业务代码只依赖接口 ──────────────────────────────────────────► │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 1.3 接口带来的好处

| 好处 | 说明 |
|------|------|
| **实现可替换** | 切换模型只需改构造代码，业务逻辑不变 |
| **编排可组合** | Agent/Graph 只依赖接口，不关心实现 |
| **测试可 Mock** | 接口天然支持 mock，无需真实调用 |
| **生态开放** | 任何人都可以实现接口贡献组件 |

### 1.4 代码示例

```go
// 定义接口
type ChatModel interface {
    Generate(ctx context.Context, messages []*Message) (*Message, error)
    Stream(ctx context.Context, messages []*Message) (*StreamReader[*Message], error)
}

// 业务代码：只依赖接口
func handleChat(model ChatModel, messages []*Message) error {
    stream, err := model.Stream(ctx, messages)
    // ... 处理流
    return nil
}

// 切换实现：只需改这一行
var model ChatModel
if useOpenAI {
    model = openai.NewChatModel(config)  // OpenAI 实现
} else {
    model = ark.NewChatModel(config)     // Ark 实现
}
```

## 2. Runnable 抽象

### 2.1 什么是 Runnable

Runnable 是 Eino 的核心抽象，表示"可执行的东西"。所有 Eino 组件都实现这个接口。

```go
type Runnable[I, O any] interface {
    Invoke(ctx context.Context, input I, opts ...Option) (output O, err error)
    Stream(ctx context.Context, input I, opts ...Option) (output *StreamReader[O], err error)
    Collect(ctx context.Context, input *StreamReader[I], opts ...Option) (output O, err error)
    Transform(ctx context.Context, input *StreamReader[I], opts ...Option) (output *StreamReader[O], err error)
}
```

### 2.2 四种数据流模式

```
┌─────────────────────────────────────────────────────────────────┐
│                      Runnable 四种数据流模式                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Invoke:                                                         │
│  ┌───────┐                      ┌───────┐                       │
│  │ input │ ───────────────────► │output │                       │
│  └───────┘                      └───────┘                       │
│                                                                  │
│  Stream:                                                         │
│  ┌───────┐     ┌──────────────────┐     ┌───────┐               │
│  │ input │ ──► │ stream (chunk1)  │ ──► │output │               │
│  └───────┘     │        (chunk2)  │     └───────┘               │
│                │        (chunk3)  │                             │
│                └──────────────────┘                             │
│                                                                  │
│  Collect:                                                        │
│  ┌──────────────────┐     ┌───────┐                             │
│  │ stream (chunk1)  │ ──► │output │                             │
│  │        (chunk2)  │     └───────┘                             │
│  │        (chunk3)  │                                           │
│  └──────────────────┘                                           │
│                                                                  │
│  Transform:                                                      │
│  ┌──────────────────┐     ┌──────────────────┐                   │
│  │ stream in        │ ──► │ stream out       │                   │
│  │ (chunk1)         │     │ (chunk1')        │                   │
│  │ (chunk2)         │     │ (chunk2')        │                   │
│  └──────────────────┘     └──────────────────┘                   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 2.3 实际应用场景

| 模式 | 场景 |
|------|------|
| **Invoke** | 简单问答、一次性生成 |
| **Stream** | 聊天机器人、实时显示 |
| **Collect** | 批量处理后汇总结果 |
| **Transform** | 流式处理流水线 |

```go
// Invoke: 简单问答
answer, err := qaChain.Invoke(ctx, question)

// Stream: 流式对话
stream, _ := chat.Stream(ctx, messages)
for {
    chunk, _ := stream.Recv()
    fmt.Print(chunk.Content)  // 实时显示
}

// Collect: 批量翻译后合并
translations, _ := translator.Collect(ctx, sentencesStream)
fullText := strings.Join(translations, "\n")

// Transform: 流式处理
processed := processor.Transform(ctx, rawStream)
```

## 3. ReAct 模式

### 3.1 什么是 ReAct

**ReAct = Reasoning + Acting**

一种让 AI 能够"思考后行动"的方法论。

### 3.2 与传统 LLM 的区别

```
┌─────────────────────────────────────────────────────────────────┐
│                    传统 LLM vs ReAct Agent                       │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  传统 LLM:                                                      │
│  ┌───────────┐                                                  │
│  │ 输入问题  │ ──────────────────────────────────────────────► │
│  └───────────┘                                                  │
│                      可能瞎编！                                    │
│                                                                  │
│  ReAct Agent:                                                   │
│  ┌───────────┐                                                  │
│  │ 输入问题  │ ──┐                                              │
│  └───────────┘   │                                              │
│                  ▼                                              │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  Thought: 我需要查一下天气                                 │   │
│  │  Action: search("北京天气")                              │   │
│  │  Observation: 今天28度，晴                                │   │
│  │  Answer: 今天北京天气晴朗，28度                          │   │
│  └─────────────────────────────────────────────────────────┘   │
│                           │                                      │
│                           ▼                                      │
│                       准确回答！                                  │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 3.3 ReAct 执行循环

```
┌─────────────────────────────────────────────────────────────────┐
│                       ReAct 执行循环                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│        ┌─────────┐                                               │
│        │  Start  │                                               │
│        └────┬────┘                                               │
│             ▼                                                    │
│  ┌─────────────────┐                                            │
│  │   LLM Generate  │  ← 生成 Thought + Action                    │
│  └────────┬────────┘                                            │
│           ▼                                                      │
│    ┌─────────────┐                                               │
│    │有工具调用？  │                                               │
│    └──────┬──────┘                                               │
│       ┌───┴───┐                                                 │
│       ▼       ▼                                                  │
│      是       否                                                 │
│       │       │                                                  │
│       ▼       ▼                                                  │
│  ┌─────────┐  ┌─────────┐                                       │
│  │ Execute │  │  Final  │ ← 直接输出答案                          │
│  │  Tool   │  │  Output │                                       │
│  └────┬────┘  └─────────┘                                       │
│       │                                                        │
│       ▼                                                        │
│  ┌─────────────┐                                               │
│  │  Observation │  ← 观察工具返回结果                             │

│         │                                                        │
│         └──────────────────────────────────────────────────┐    │
│                                                              │    │
│                                                              │    │
│                                         循环回 LLM Generate  ◄─┘    │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 3.4 ReAct 代码实现

```go
// 1. 创建 Agent
agent, err := react.NewAgent(ctx, &react.AgentConfig{
    Model: model,
    ToolsConfig: compose.ToolsNodeConfig{
        Tools: []tool.BaseTool{
            searchTool,    // 搜索工具
            calculatorTool, // 计算器工具
        },
    },
    MaxStep: 10,  // 最多迭代10次，防止死循环
})

// 2. 执行
events := agent.Run(ctx, &AgentInput{
    Query: "北京今天能穿短袖吗？",
})

// 3. 处理事件
for event := range events.Iter() {
    if event.Err != nil {
        log.Fatal(event.Err)
    }

    if event.Action != nil {
        if event.Action.BreakLoop != nil {
            // Agent 结束
            break
        }
    }

    if event.Output != nil {
        fmt.Println(event.Output.Message.Content)
    }
}
```

## 4. Graph 编排

### 4.1 什么是 Graph

Graph 是一种有向无环图（DAG）编排方式，支持复杂的节点连接。

```
┌─────────────────────────────────────────────────────────────────┐
│                         Graph 结构示意                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  START ────────────────┐                                        │
│                        │                                        │
│                        ▼                                        │
│                  ┌───────────┐                                   │
│                  │  Input    │                                   │
│                  └─────┬─────┘                                   │
│                        │                                        │
│          ┌─────────────┼─────────────┐                          │
│          ▼             ▼             ▼                          │
│    ┌───────────┐ ┌───────────┐ ┌───────────┐                    │
│    │ Branch A  │ │ Branch B  │ │ Branch C  │                    │
│    └─────┬─────┘ └─────┬─────┘ └─────┬─────┘                    │
│          │             │             │                          │
│          └─────────────┼─────────────┘                          │
│                        ▼                                        │
│                  ┌───────────┐                                   │
│                  │  Merge    │                                   │
│                  └─────┬─────┘                                   │
│                        │                                        │
│                        ▼                                        │
│                      END                                         │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 Graph vs Chain

| 特性 | Chain | Graph |
|------|-------|-------|
| 结构 | 线性 | 有向无环图 |
| 分支 | 不支持 | 支持 |
| 合并 | 不支持 | 支持 |
| 复杂度 | 简单 | 复杂 |
| 适用场景 | 固定流程 | 条件分支 |

### 4.3 Graph 代码示例

```go
// 1. 创建 Graph
g := compose.NewGraph[*Input, *Output]()

// 2. 添加节点
g.AddLambdaNode("input_processor", inputLambda)
g.AddChatModelNode("llm", model)
g.AddToolsNode("tools", toolsNode)
g.AddLambdaNode("output_formatter", outputLambda)

// 3. 添加条件分支
checkFunc := func(ctx context.Context, msg *Message) (string, error) {
    if len(msg.ToolCalls) > 0 {
        return "tools", nil  // 有工具调用
    }
    return "output_formatter", nil  // 直接输出
}

branch := compose.NewStreamGraphBranch(checkFunc,
    map[string]bool{
        "tools": true,
        "output_formatter": true,
    })
g.AddBranch("llm", branch)

// 4. 连接边
g.AddEdge(compose.START, "input_processor")
g.AddEdge("input_processor", "llm")
g.AddEdge("tools", "llm")  // 工具执行后回到 LLM
g.AddEdge("output_formatter", compose.END)

// 5. 编译执行
runner, err := g.Compile(ctx)
result, err := runner.Invoke(ctx, input)
```

### 5.2 Agent 事件流

```go
// Agent 执行返回异步迭代器
events := agent.Run(ctx, input)

// 事件类型
type AgentEvent struct {
    AgentName string              // Agent 名称
    RunPath   []RunStep           // 执行路径
    Output    *AgentOutput        // 输出内容
    Action    *AgentAction        // 特殊动作
    Err       error               // 错误
}

// 处理事件
for event := range events.Iter() {
    switch {
    case event.Err != nil:
        // 错误处理
    case event.Action != nil:
        switch {
        case event.Action.Exit:
            // Agent 自然结束
        case event.Action.Interrupted != nil:
            // 被中断，等待用户确认
            userConfirm(event.Action.Interrupted)
        case event.Action.TransferToAgent != nil:
            // 转移到其他 Agent
        case event.Action.BreakLoop != nil:
            // 跳出循环
        }
    case event.Output != nil:
        // 正常输出
        fmt.Println(event.Output.Message.Content)
    }
}
```

## 6. 流式处理

### 6.1 为什么需要流式

| 模式 | 用户体验 | 实现复杂度 |
|------|---------|----------|
| 非流式 | 等待全部生成才显示 | 简单 |
| 流式 | 逐字显示，像打字 | 复杂 |

### 6.2 StreamReader 核心操作

```go
// 创建管道
sr, sw := schema.Pipe[string](bufferSize)

// 生产者写入
go func() {
    for _, chunk := range chunks {
        sw.Send(chunk)
    }
    sw.Close()
}()

// 消费者读取
for {
    chunk, err := sr.Recv()
    if err == io.EOF {
        break
    }
    fmt.Print(chunk)
}
```

### 6.3 流的复制

一个流只能读一次，需要复制给多个消费者：

```
┌─────────────────────────────────────────────────────────────────┐
│                        流复制 (Copy)                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│       ┌─────────┐                                                │
│       │ Stream  │                                                │
│       │   sr    │                                                │
│       └────┬────┘                                                │
│            │ Copy(2)                                             │
│       ┌────┴────┐                                                │
│       ▼         ▼                                                │
│  ┌─────────┐ ┌─────────┐                                        │
│  │  srs[0] │ │  srs[1] │                                        │
│  │ (输出)  │ │ (保存)  │                                        │
│  └────┬────┘ └────┬────┘                                        │
│       │           │                                             │
│       ▼           ▼                                             │
│   HTTP SSE    收集到数组                                          │
│   实时显示    保存记忆                                            │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 6.4 完整流式处理示例

```go
// 1. 获取流
stream, err := agent.Stream(ctx, messages)
srs := stream.Copy(2)  // 复制成两个流

// 2. goroutine: 保存记忆
go func() {
    fullMsgs := make([]*schema.Message, 0)
    for {
        chunk, err := srs[1].Recv()
        if err == io.EOF {
            break
        }
        fullMsgs = append(fullMsgs, chunk)
    }
    conversation.Append(fullMsgs)  // 保存到记忆
}()

// 3. 主线程: 流式输出
return srs[0], nil  // 返回流给 HTTP
```

## 总结

| 概念 | 核心作用 |
|------|---------|
| **Component** | 统一接口，实现可替换 |
| **Runnable** | 四种数据流模式 |
| **ReAct** | 思考+行动的 Agent 模式 |
| **Graph** | 复杂 DAG 编排 |
| **Agent** | 自主决策的智能体 |
| **StreamReader** | 流式数据处理 |

理解这些核心概念后，你就能更好地理解 Eino 框架的设计哲学和使用方式。
